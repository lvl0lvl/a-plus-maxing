# Build Plan: Model-Based Universal Ingestion — Any-Format Upload Extraction via the No-Train Lane (ADR-0030)

Scope: the approved ADR-0030 spec (5 tasks T1..T5) that builds a NEW FRONT DOOR onto the frozen ingest engine — route a browser-uploaded file of ANY unrecognized format through the operator's already-authorized no-train model lane to EXTRACT structured `(item, timepoint, source, value)` Line-Field-Set readings, surface EVERY extracted reading to the operator for review, and land ONLY operator-confirmed readings through the UNCHANGED `store.append` sink. The deliverable is the universal-ingestion slice: a no-train `extract_readings` method mirroring the live `deidentify`/`converse` (T1), an unrecognized-format branch on `route_upload` that dispatches to `extract_readings` without auto-landing (T2), a `POST /upload` surface that renders extracted readings for review + a `POST /confirm-extraction` route that lands only the confirmed subset (T3), the SPA `Upload Documents` confirm UI (T4), and the headline end-to-end proof + the four ADR-0030 falsification probes as tests (T5). This realizes ADR-0030 (which §amends ADR-0001/0003/0013/0029 to authorize the ONE ingestion-extraction egress class on the no-train lane); it does NOT re-decide them.

The crown-jewel obligation is load-bearing and unchanged: the ONLY egress of file content is the no-train lane — 0 file bytes to any non-no-train endpoint, preserved structurally by keeping the single model-client SDK import inside `scripts/model/` and routing the file only into the injected `client.extract_readings` (NFR-1). HONEST DATA: no model-extracted reading lands without an operator-confirm step (the confirm-gate, NFR-2); no extraction failure fabricates a reading (fail-closed, NFR-3). EXTEND-NOT-REBUILD: the byte-frozen ingest engine (`scripts/ingest/ingest.py`, `scripts/ingest/adapter.py`) + the Line-Field-Set + `store.append` + every `scripts/plan/*.py` (including the `scripts/plan/deid_in.py` de-id boundary) stay numstat=0 every wave (NFR-4); the extraction is a new front door, not an engine edit. OQ-5: the raw uploaded file lives only in memory / the gitignored OS-temp staged path and is never written to a tracked path (NFR-5). The build is MOCK/FIXTURE-tested with 0 live-API spend at the ADR-0015 backend seam (NFR-6); the operator-present LIVE run (real key + real file + real spend, the OS-egress-guard LIVE form of the crown-jewel probe) is OQ-1, the operator-gated checkpoint AFTER this build, in NO wave. Tier-1 deterministic format-family detectors + the local `pdftotext`/`marker` zero-egress fast-path are OQ-2, explicitly OUT of scope.
