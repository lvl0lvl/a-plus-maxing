# Build Plan: Local-Extraction-First PDF Ingestion + Genetics Genotype-Fact Capture (ADR-0031)

Scope: the approved ADR-0031 spec (6 tasks T1..T6) that adds a NEW LOCAL-EXTRACT FRONT MODULE onto the frozen ingest engine — for an unrecognized-format PDF upload, extract the text LOCALLY first (`pdftotext` deterministic primary, `marker_single` fallback on low-text — both 0-network local subprocesses), then send only the extracted TEXT (never the raw `document` block) to the no-train model for structuring over the existing `text` content-block path, CHUNKED so the structured output never truncates and every finding is captured, aggregated + deduped through the UNCHANGED `keying`/`store.append` sink, with genetics findings captured as DURABLE GENOTYPE FACTS (item=gene+rsID, timepoint=sample-date, source=`dna-report`, value=alleles). The deliverable: the local PDF→text extractor (T1), the chunk-aggregate-dedupe-with-honest-partial-signal module (T2), the genetics genotype-fact extract-prompt mapping (T3), the route wiring + the server `/upload` partial-signal surfacing (T4), the SPA honest-partial note (T5), and the headline E2E + the six ADR-0031 falsification probes as tests (T6). This AMENDS the now-live ADR-0030 file→model mechanism; it does NOT re-decide it.

The crown-jewel obligation is load-bearing and TIGHTENED relative to ADR-0030: for a PDF the raw binary stays LOCAL (it reaches only the `pdftotext`/`marker` subprocess) and the ONLY egress is the scopeable extracted TEXT on the authorized no-train lane — 0 raw-binary bytes egress to ANY endpoint (including the no-train lane), 0 text bytes to any non-no-train endpoint, 0 network calls from the local extractor subprocess (NFR-1). HONEST DATA + COMPLETENESS: confirm-before-land is unchanged (no auto-land); a too-large/garbled document surfaces an operator-visible partial/too-large signal, NEVER a silent "no new data" (the exact prior live failure); the genetics path stores the durable genotype FACT not the dated interpretation; no fabricated genotype (NFR-2/NFR-4). EXTEND-NOT-REBUILD: the byte-frozen ingest engine (`scripts/ingest/{ingest,adapter}.py`) + every `scripts/plan/*.py` + `scripts/store/keying.py` + `scripts/store/store.py` (the `store.append` sink) stay numstat=0 every wave; the local-extract step is a NEW front module (`scripts/ingest/pdf_extract.py` + `scripts/ingest/extract_chunked.py`), not an engine edit (NFR-3). OQ-3: both the raw uploaded binary and the extracted text live only in memory / the gitignored OS-temp staged path and are never written to a tracked path (NFR-6). The build is MOCK/FIXTURE-tested at 0 live-API spend at the ADR-0015 backend seam, with a real `pdftotext` (`skipif`-gated) and a STUBBED `marker` — never a real heavy `marker` run / model download (NFR-5). The operator-present LIVE run (real key + the real 42-page genetics report + real spend, the OS-egress-guard LIVE form of the raw-binary-egress + local-extractor-network probes) is OQ-1, the operator-gated checkpoint AFTER this build, in NO wave.
