# Build Plan: Unified Inline-Asset SPA Front-End — Realize the Intake Slice on the New Surface (ADR-0029)

Scope: the approved ADR-0029 spec (5 tasks T1..T5) that WIRES the operator-approved four-screen SPA (`prototype/app.html` — a persistent left-nav shell `Dashboard` / `Upload Documents` / `Plan` / `Chat with Team`) to the already-built conversational-intake backend so the operator's REAL data can flow in through the new surface. The deliverable is the intake-first slice: the SPA becomes a TRACKED inline-asset render-view served as the GET `/` body of the existing loopback server (its off-file assets vendored inline so `render.emit` will emit it), the one remaining backend gap (live `converse`) lands, the `Upload Documents` surface (the ADR-0018 form/chat split realized as one screen) is wired to the built `/upload` capture seam + the built `/chat` egress seam, and the one absent integration proof (the conversation→usable-plan E2E) is created. This realizes ADRs 0013-0019 on the new front-end; it does NOT re-decide them.

Five tasks across three waves: **T1** ports `app.html` into a tracked inline-asset render-view module (`vault/design/templates/app_shell.py`), re-points the GET `/` body source from `generate.run("intake")` → `generate.run("app")`, vendors lucide + inlines-or-removes `images/body.png` so `render.emit` returns a path (the AUTHORITATIVE inline-asset check, not a grep), renders honest awaiting-states for Dashboard/Plan/Team, and re-points/retires the 19 `WIZARD_TITLE` assertion sites (no tautological dead-wizard test). **T2** implements the live `_ClaudeNoTrainBackend.converse` (today a `NotImplementedError` stub) mirroring the implemented `deidentify` — same lazy `_client()` + runtime `key_source.resolve`, bounded retry, fail-closed `ModelCallError` with `from None`, mock-tested, 0 live spend. **T3** wires the `Upload Documents` surface: the demographic "About you" form gets real `name=` → `/upload` (the 4 tokens, the 6-band kg→lb select built from the gate enums), the chat composer fetches `/chat` + renders the receipt, and the ingestion-state renders the real `ingest.status.resolve` load-state (0 fabricated counts). **T4** proves the SPA-surface elicitation is not-naive (a fresh operator with sentinel bands is ASKED the gap; the `not-discussed`/`none`/`moderate` sentinels read as a GAP, never vacuous `domain_done`/`intake_complete` — PF-S87-01; failing-capable negative control). **T5** proves the headline conversation→usable-plan E2E through the SPA-served path (compose ADR-0017-T2: `recorded == True` + content-traceability + a failing-capable negative control — NON-TAUTOLOGICAL).

The crown-jewel obligation is unchanged: 0-leak (no raw operator PII past the de-id boundary; every persisted fact de-identified via the unchanged extractor + capture gate + `summarize`; the served front-end introduces 0 new outbound class beyond the ADR-0016 one-turn `/chat`). Every task EXTENDS-NOT-REBUILDS: the byte-frozen inner plan engine (`scripts/plan/{orchestrate,pipeline,assemble,generate_plan,adjudicate,adjust,track,router}.py`) + the `deid_in` de-id-IN boundary stay numstat=0 (a wave-checkpoint probe, NFR-4); only `vault/design/templates/app_shell.py` (new) + `scripts/generate/generate.py` + `scripts/serve/server.py` + (only the `converse` method of) `scripts/model/client.py` + tests change. The build is MOCK/FIXTURE-tested with 0 live-API spend; the LIVE operator-present run (real key + real data + spend) is the operator-gated checkpoint AFTER this build, NOT in any wave.
