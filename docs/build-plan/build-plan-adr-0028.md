# Build Plan: Gate-Dispatch Control-Inversion — Completing the A′ Subscription Driver (ADR-0028)

Scope: the approved ADR-0028 spec (5 tasks T1..T5) that completes the A′ control-inversion the S93 build left PARTIAL. Today `plan_driver.drive` inverts only the AUTHOR dispatch (a bare author-tuple `yield (tuple(domains), summary, gates)` at [plan_driver.py:122](../../../../scripts/plan/plan_driver.py)); the GATE is still a SYNCHRONOUS `_safe_gate(gate_dispatch, result)` in `drive`'s frame ([plan_driver.py:129](../../../../scripts/plan/plan_driver.py)) and the REAUTHOR/ADJUDICATOR hooks are still synchronous callables threaded INSIDE the byte-frozen `orchestrate.generate_plans` (`reauthor("workout", {...})` at [orchestrate.py:550](../../../../scripts/plan/orchestrate.py); `_adjudicate_with_band(safety_finding, adjudicator)` at [orchestrate.py:578,595,613](../../../../scripts/plan/orchestrate.py)). Under the operator's binding runtime split — API for the PII de-id call ONLY, subscription for everything else — those four dispatches must run as SUBSCRIPTION agents (Agent-tool dispatches the `/generate-plan` skill issues), so the live A′ run halts at `_safe_gate`. This build inverts the remaining classes by TWO mechanisms keyed to call-stack position.

Five tasks across four waves: **T1** extends `drive`'s yield from the bare author-tuple to a typed discriminated-union request and inverts AUTHOR + GATE by DIRECT YIELD (both fire in `drive`'s frame); the GATE becomes a yielded request carrying the assembled plan + judge + lens roster, the consumer `.send()`s raw verdicts, `drive` still composes via `compose_gate_dispatch` + applies `safety_passed is True` — composition in ONE place. **T2** inverts REAUTHOR + ADJUDICATOR by THROW/REPLAY-MEMOIZATION (they fire inside the byte-frozen engine and cannot yield without editing it): the consumer supplies memo-cache-backed `reauthor`/`adjudicator` callables that raise a `BaseException`-subclass sentinel on a cache-miss, unwinding to `drive`, which yields the typed request, caches the `.send()` envelope, and re-drives the pass over a FRESH scratch store; charge-on-cache-miss-only. **T3** builds the step-harness `scripts/plan/plan_step.py` (the skill's per-round drive) + pins the memo-cache serialization format + a determinism audit (OQ-5). **T4** reconciles `/generate-plan` SKILL.md to drive via `plan_step.py` + adds the NEW value-scan over the GATE/ADJUDICATOR yield payloads (the first-ever such scan over those DERIVED artifacts). **T5** extends the self-test / E2E to NON-TAUTOLOGICALLY exercise the REAUTHOR + ADJUDICATOR replay paths.

The crown-jewel obligation is unchanged: 0-leak (no raw operator PII past the de-id-IN boundary, into any yielded dispatch payload, or into any committed file) and a single un-forked fail-closed safety loop (`safety_passed is True` the only surface path; `compose_gate_dispatch` the only disposition composer; the adjudication RELEASE stays in the inner engine's `adjudicate`). Every task EXTENDS-NOT-REBUILDS: the byte-frozen INNER ENGINE (`scripts/plan/{orchestrate,pipeline,assemble,generate_plan,adjudicate,adjust,track,router}.py`) stays numstat=0; only `plan_driver.py` + `plan_orchestrator.py` + (at the raw-verdict boundary only, if at all) `gate_dispatch.py` + the new `plan_step.py` + the SKILL.md + tests + `_a_prime_self_test.py` change.
