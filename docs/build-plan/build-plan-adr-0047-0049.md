# Build Plan: Alpha-Tester Credential Onboarding (ADR-0047…0049, Tiers 1-2)

Scope: the approved single spec (`docs/spec/adr-0047-0049-credential-onboarding-spec.md`, 10 tasks) that lets an alpha tester connect a wearable and reach the model in-app, on Mac or Windows, without a shell — the cross-platform `keyring`-backed secret-store abstraction + encrypted-file/env fallback (ADR-0047), app-mediated OAuth onboarding — localhost PKCE callback, N-per-source writes, the intake credential step + My Info "Connections & Keys" panel, out-of-band shared-credential distribution (ADR-0048), and cost governance for the shared metered lane — a bounded metered dispatch factory, a manual-default plan-update trigger with an Off/Weekly/Daily schedule, and a per-tester monthly spend cap (ADR-0049). The wave schedule is GROUNDED on the spec's already-built Dependency Map (13 edges, 6 Kahn parallel groups, verified acyclic), File Manifest, and Test Strategy — this plan schedules them; it independently RE-DERIVES (does not transcribe) the waves, critical path, and per-wave file-disjointness against the live tree.

## Overview / Governing Constraints

**This build is a mock/fixture build at $0.** Fixture OAuth, fixture model clients, mocked per-OS keyring backends. The operator-present LIVE run (real shared key, real data, real spend, dev-app registration for the exact per-vendor client types) is operator-gated (bead `a-plus-maxing-m8ia`) and is OUT of this plan's scope — a post-build operator step, NOT a wave. The build rides four checkpoint invariants on EVERY wave, none deferred to the last:

1. **Frozen-six HARD byte-freeze for the ENTIRE build — NO sanctioned break.** Unlike the ADR-0041…0046 re-architecture (which deliberately superseded four plan-spine surfaces), THIS build lands EVERY task OUTSIDE the ADR-0032 frozen six. `<frozen-six>` = `scripts/store/store.py scripts/store/keying.py scripts/plan/pipeline.py scripts/plan/adjudicate.py scripts/plan/adjust.py scripts/plan/router.py`. The freeze is asserted at every wave boundary AND the terminal by `git diff --numstat 3ab1c3ab -- <frozen-six>` == EMPTY. **The numstat base is the durable fork-point SHA `3ab1c3ab`** (commit "Add ADR-0049 alpha cost governance (#348)", 2026-07-14 — verified present, frozen-six clean at entry), **NEVER the dynamic merge-base** (PF-S133-03): a merge-base drifts as `main` advances and silently changes what the probe forbids. There is no per-ADR supersession probe in this build — the six stay byte-identical throughout.

2. **Crown-jewel non-egress — two load-bearing wire-scans (ADR-0001 egress rulings).** The **D2 metered-lane** scan (ADR-0049-T1, Wave 3): the metered specialist/judge/lens adapter is injected DOWNSTREAM of the `deid_in` de-id boundary, so its ACTUAL OUTBOUND payload ⊆ `SUMMARY_FIELD_SET`, 0 raw-PII, 0 store bytes, 0 store reads; lane-swap-invariant; mutation-gated (a raw-field-appending or store-reading stub MUST flip it RED). The **D7 OAuth** scan (ADR-0048-T2, Wave 4): the authorize+callback+token-exchange path carries 0 store bytes / 0 no-train-model-lane calls / vendor-only outbound host, per-family mutation-RED including the cross-host-redirect leak. Each scan asserts the CLEAN direction truthy FIRST, then RED-gates EACH family with the self-invalidation clause ("the test is invalid — and fails — if that mutation does not RED it").

3. **CSRF fail-closed on every new forced-spend / secret-write route.** The new per-source secret-write route (ADR-0048-T3, Wave 3) and the forced-spend "Update my plan now" trigger (ADR-0049-T2, Wave 6) each carry the SEC `application/json` gate: a cross-site CORS-simple `text/plain` POST is refused 415 BEFORE any keychain write or any metered spend, mutation-proven RED if the gate is dropped. The new inbound OAuth boundary (ADR-0048-T2, Wave 4) is fail-closed by its analogous guards — `state`/PKCE mismatch and cross-host-3xx decline each produce 0 token writes before the guard passes. The shared-key provisioning **bridge (F3, ADR-0048-T1 → ADR-0049-T1)** is itself fail-closed: it closes the default-path `KeyUnavailableError` on the D5 "touch nothing" path (RED if the bridge is removed) and no-ops on a bring-your-own key (0 clobber).

4. **0 live-API spend / 0 real operator PII, and store-surface discipline is N/A.** Every one of the 10 tasks is satisfiable with mocked per-OS keyring backends, fixture OAuth, fixture model clients, and synthetic PII-free seeds; no test opens a live socket or makes a live model/OAuth call (`anthropic` SDK intentionally absent from `requirements.txt` — the 0-live-spend guard). **NO task reads from or writes to `scripts/store/`** (spec File-Manifest note, confirmed live) — the D5 spend ledger (ADR-0049-T3) persists to a gitignored instance-local path, never `scripts/store/`, and the D2 scan asserts the metered adapter performs 0 store reads. **The store-adversarial blocking gate (`docs/checklists/store-adversarial-tests.md`) therefore does NOT trigger** — stated explicitly so no wave carries a phantom store-battery obligation.

Grounded live against `feature/credential-build-plan` (2026-07-15): `3ab1c3ab` present + frozen-six numstat EMPTY vs it; all 5 Create targets (`scripts/secret_store/__init__.py`, `scripts/serve/alpha_config.py`, `scripts/serve/oauth_callback.py`, `scripts/runner/metered_dispatch.py`, `scripts/runner/spend_cap.py`) ABSENT; all Modify targets (`scripts/model/key_source.py`, `scripts/runner/auth_isolation.py`, `scripts/ingest/oauth_pull.py`, `scripts/serve/server.py`, `vault/design/templates/intake.py`, `vault/design/templates/app_shell.py`) present; `keyring` ABSENT from `requirements.txt` and un-importable today (confirms the first-time dep); `server.py` carries the cited `application/json` CSRF gate + `_save_key`/`_key_status`/`_do_plan_loop`/`/plan-loop` anchors.
