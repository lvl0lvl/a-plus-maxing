## ADR-0051: Surface the Raw Genetic Panel to Specialists Identity-Stripped (Reverse the Genotype Carve-Out)

> **Y-Statement:** In the context of the plan path, where a specialist personalizes only off the signal it receives and genetics reaches it solely as ADR-0032's coarse `genetic-trait-classes` token — 8 derived classes from the 10 (gene, rsid) tuples across 9 genes that `PLANNING_RELEVANT_VARIANTS` curates ([variants.py:10-28](../../scripts/genetics/variants.py) [VERIFIED]), while the operator's store holds 115 raw `dna-report` genotype items ([store `find` = 115 VERIFIED]) — so ~105 stored SNPs are invisible to the author because the raw rsID+allele genotype NEVER crosses (the ADR-0032/0042 crown-jewel carve-out), facing the tension that the operator now wants the specialists reasoning over the FULL raw panel and has set the de-identification standard to identity-stripping ONLY (all raw health substance flows identity-stripped, genotypes included) against the fact that a genome is inherently re-identifying so stripping identity tokens does not anonymize it, we decided to REVERSE the genotype carve-out and carry the operator's raw `dna-report` genotypes to the specialists through the assembler's existing `pii_scan` identity-strip — the same gate that already carries raw lab values, medications, and health free-text — keeping ADR-0032's derived `genetic-trait-classes` token as a de-identified summary alongside the raw, to achieve specialists reasoning over the operator's stored genetic panel (minus ADR-0032's preserved sensitive-variant exclusions) instead of 8 coarse classes, accepting (operator-signed-off and revisitable — "just go raw genotypes for now") that raw, immutable, disease-risk-revealing genetic data now transits to an external no-train API, that identity-stripping cannot anonymize a genomic fingerprint, and that the ~105 uncurated SNPs reach the specialist UN-VETTED by ADR-0032's library (the model interprets them from its own knowledge).

### Context

A dispatched specialist personalizes only off the signal it receives, and for genetics that signal is the coarse `genetic-trait-classes` token — a `;`-joined set of derived functional classes ([router.py:59,178,305](../../scripts/plan/router.py) [VERIFIED]) whose coverage is the 10 (gene, rsid) tuples across 9 genes (ACTN3, CYP1A2, MTHFR×2, FADS2, MCM6, MTNR1B, FTO, SOD2, ADIPOQ) that `PLANNING_RELEVANT_VARIANTS` curates and `match_genotypes` resolves against the local library ([variants.py:10-28](../../scripts/genetics/variants.py); [match.py:118-140](../../scripts/genetics/match.py) [VERIFIED]). The operator's store holds 115 raw `dna-report` genotype items keyed `<GENE> <rsID>` with an allele-call value — e.g. `{"item": "MTNR1B rs10830963", "source": "dna-report", "value": "(C;C)"}` [VERIFIED: store read]. So ~105 stored SNPs are invisible to the author: today the raw rsID+allele genotype NEVER crosses to the model — ADR-0032 keeps it 100% local and feeds only the derived token, and ADR-0042's RT-008 carve-out excludes raw genotypes from "all health substance flows" ([ADR-0032, Decision](ADR-0032-dna-aware-planning.md); [ADR-0042, Decision §2](ADR-0042-context-assembler-full-record.md) [VERIFIED]). The assembler enforces that mechanically: it rejects any carried value matching a raw genotype ([context_assembler.py:178-187](../../scripts/plan/context_assembler.py) [VERIFIED]).

The de-identification posture that bounds this is no longer the genotype carve-out — the operator has RESET the standard. The de-id standard is now identity-stripping ONLY: all raw health substance flows to the specialists identity-stripped, INCLUDING raw genotypes ("just go raw genotypes for now" — operator directive). This is the boundary ADR-0042 already realized for lab values, medications, and health free-text, which cross the assembler's `_HEALTH_SUBSTANCE_ALLOWLIST` uncollapsed through the `pii_scan` identity-strip ([context_assembler.py:54-65,188-193](../../scripts/plan/context_assembler.py) [VERIFIED]); genetics was the one carved-out exception. ADR-0042 already amended ADR-0001's plan-path boundary from summaries-not-raw over the closed field-set to "full health substance minus identity" ([ADR-0042, amends ADR-0001](ADR-0042-context-assembler-full-record.md) [VERIFIED]) — ADR-0032 had rejected raw-genotype-to-model as the exact breach ADR-0001's falsification names; this decision completes that ADR-0001 amendment for the one class ADR-0042 left carved out.

Two forces pull against each other across more than one stakeholder. The operator and the physician want the specialists reasoning over the operator's FULL raw genetic panel — the coarse 8-class token discards the ~105 uncurated SNPs, and a specialist cannot personalize off data it never sees. Against that stands the data subject's most durable exposure: a genome is inherently re-identifying — the combination of many SNP calls is a unique, immutable, disease-risk-revealing fingerprint that identity-token stripping does not and cannot anonymize (the `pii_scan` gate catches names, contact, DOB, SSN — not the biometric identity of the genome itself, [pii_scan.py:505-517,611](../../scripts/guard/pii_scan.py) [VERIFIED]). Because this REVERSES a crown-jewel invariant two prior decisions built and froze — the raw genotype crossing to an external model — it is a decision, not a code comment beside the assembler.

### Decision

Reverse the raw-genotype carve-out: carry the operator's raw `dna-report` genotypes (rsID + allele call, all stored SNPs) to the specialists identity-stripped, through the assembler's existing `pii_scan` identity-strip — the same gate already applied to the raw lab values, medications, and health free-text ADR-0042 carries ([context_assembler.py:188-193](../../scripts/plan/context_assembler.py) [VERIFIED]). The specialists author from the raw genotypes, not only the derived trait-classes.

1. **Raw genotypes flow, identity-stripped.** The raw `dna-report` genotype items cross to the specialist through the assembler; each carried value transits the reused `pii_scan.scan_operator_value` identity gate and fails closed on operator identity smuggled into a genetics field.
   - **ADR-0032's sensitive-variant exclusions are PRESERVED by default.** APOE / DRD2 / BDNF (ADR-0032's "sensitive / non-actionable, never auto-crossed; APOE is a medical conversation" set — the operator's store holds DRD2 rs1800497 + BDNF rs6265 [VERIFIED]) do NOT cross raw; the operator gets their derived signal only. Crossing the sensitive set raw is a SEPARATE explicit operator call, not implied by "identity-only" (OQ-3). The raw carry is the stored panel MINUS this exclusion set.
2. **The derived token STAYS as a de-identified summary alongside the raw.** ADR-0032's `genetic-trait-classes` token, its de-associated variant research, the local library, and `match_genotypes` all persist and are UNCHANGED; the raw genotypes are added ALONGSIDE the derived summary, not in place of it. `variants.py` trait-class widening (the prior ADR-0051 draft's subject) becomes OPTIONAL — a nice-to-have for the summary layer, not required, since the raw genotypes are now the personalization signal.
3. **The safety invariant is now identity-only.** No IDENTITY (legal name, DOB, contact, MRN/insurance-id/provider-name) reaches the model; the `pii_scan` identity-strip holds on the raw genetics exactly as on the other raw carries. There is no longer a raw-genotype exclusion.
4. **Synthetic/mock only; the live run is operator-gated.** Built and mock/fixture-tested at 0 live spend; the operator-present LIVE run (real spend, real genotypes to the API) is operator-gated (OQ-4), as with ADR-0032 OQ-1 / ADR-0042 OQ-4.

The change lands in `context_assembler.py` — NOT in `router.py` or the frozen ADR-0032 inner engine. The derived `genetic-trait-classes` token and its fail-closed backstop ([router.py:305-314](../../scripts/plan/router.py) [VERIFIED]) are UNAFFECTED, because the raw genotypes flow via the assembler's genetics carry, NOT via the trait-classes token (the backstop still correctly forbids a genotype in the derived token). Two assembler-local reworks this decision requires — SCOPING the genotype-rejection at [context_assembler.py:178-187](../../scripts/plan/context_assembler.py) to exempt ONLY the genetics read path (the guard STAYS on every non-genetics carry by default — blanket removal is a silent safety-property loss, OQ-2), and choosing a carry mechanism that does not force a `router.EXCLUDED_RAW_PII` edit — are named in Consequences and OQ-1/OQ-2.

### Rationale

Three options were weighed against four criteria the operator's reset makes load-bearing — **personalization reach** (how much of the panel the specialist sees), **de-id posture** (what the standard now is), **maintenance cost**, and **freeze-compatibility**.

On **personalization reach**, only the raw carry removes the ceiling: the derived-classes path shows 8 classes from 10 curated tuples, so ~105 of 115 stored SNPs stay invisible however the mapping is widened; the raw genotypes surface all 115. On **de-id posture**, the raw carry is the direct expression of the operator's reset standard — identity-stripping only, one rule for all raw health substance, genotypes no longer special — which removes the genetics carve-out as a maintained exception rather than growing a second one. On **maintenance cost**, the raw carry ends the curation ceiling entirely (no per-SNP library finding is required for a genotype to reach the specialist), where widening the derived mapping (the prior draft) would have made the curated set a permanent, panel-varying burden. On **freeze-compatibility**, the raw carry lands in `context_assembler.py` — a post-ADR-0042 file, not in the ADR-0032 frozen inner-engine glob nor `router.py` — provided the genetics carry uses a `dna-report`-source read path rather than the `_HEALTH_SUBSTANCE_ALLOWLIST` field mechanism (whose load-time partition assert, [context_assembler.py:80-84](../../scripts/plan/context_assembler.py) [VERIFIED], would otherwise force adding a genetics class to `router.EXCLUDED_RAW_PII` — a router.py edit; see OQ-1).

The cost the chosen path accepts is the deepest privacy exposure in the system, and it is not mitigable by the identity strip: a genome is a fingerprint, so "identity-stripped" does not mean anonymous. The operator signed this off explicitly and framed it as provisional ("for now"), so the decision is recorded as reversible — Alternative B (the derived-classes path) is the standing retraction target if the re-identification risk is later judged unacceptable. Long-term, the raw genotypes become the specialists' genetic input contract that ADR-0050's wiring and the specialist prompts consume, so the specialist prompt must be able to interpret rsID+allele calls (an ADR-0050 concern, surfaced in Consequences).

### Consequences

**Positive:**
- Specialists reason over the operator's raw genetic panel — the stored SNPs minus ADR-0032's preserved sensitive-variant exclusions, not the 8 derived classes from 10 curated tuples ([variants.py:10-28](../../scripts/genetics/variants.py), store `find` = 115 [VERIFIED]) — a far larger genetic personalization signal.
- The curation ceiling is gone: a genotype no longer needs a curated `PLANNING_RELEVANT_VARIANTS` tuple + a gated library finding to reach the specialist, so the prior draft's permanent per-SNP curation burden does not apply.
- A single uniform de-id standard: identity-stripping only, one rule for all raw health substance (genotypes included), so there is no genetics carve-out to maintain as a special exception — one boundary to audit ([context_assembler.py:188-193](../../scripts/plan/context_assembler.py) [VERIFIED]).
- Reuses the existing assembler + `pii_scan` gate; ADR-0032's derived token, variant library, and de-associated research all persist unchanged as the de-identified summary layer.

**Negative:**
- **Raw genotypes are INHERENTLY re-identifying, and identity-stripping does NOT anonymize them (operator-accepted, revisitable "for now").** A genome is a unique, immutable, disease-risk-revealing fingerprint; the `pii_scan` gate catches identity tokens (name/DOB/contact/SSN) — not the biometric identity of the genome itself ([pii_scan.py:505-517](../../scripts/guard/pii_scan.py) [VERIFIED]). Raw, immutable genetic data now transits to an external no-train API. This is the highest-stakes and least-mitigable exposure in the system; it is signed off and provisional, not eliminated.
- **The ~105 uncurated SNPs reach the specialist UN-VETTED — an honest-data / read-currency regression distinct from privacy (touches ADR-0009).** ADR-0032 routed genetics through the ingestion-gated `aplus-research` library precisely so the genetic read rested on current, cited, vetted science, never an invented read ([ADR-0009 honest-data principle](ADR-0009-dashboard-visual-shell-seven-zones.md), which records `complements ADR-0032` [VERIFIED]). That vetted layer covers ONLY the ~10 curated variants with a library finding; for the ~105 uncurated stored SNPs there is NO finding, so the specialist model interprets the raw `(C;C)` call from its OWN ungated, possibly-stale-or-hallucinated genetic knowledge. On a physician-visit deliverable that is a clinical-safety regression the privacy analysis does not cover. Honestly scoped: the derived/library layer stays the VETTED read for the curated variants; the raw carry is un-vetted-by-construction for the rest, and no gate makes it current-cited (OQ-5).
- **The `pii_scan` identity strip must be VERIFIED to actually catch operator identity embedded in a raw genetics payload** — a name or DOB smuggled into a `dna-report` field, not just the structured `(C;C)` value. The genetics carry's safety now rests entirely on that gate being complete for this new payload shape (Validation, the identity-leak probe).
- **The specialist prompt (ADR-0050) must interpret rsID+allele calls.** The specialists now receive `MTNR1B rs10830963 = (C;C)`-shaped data; if the ADR-0050 authoring prompt cannot read genotype calls, the raw signal is carried but unused — a wiring dependency, not a boundary risk.
- **The assembler's own genotype-rejection must be SCOPED (not blanket-removed) for the genetics carry.** [context_assembler.py:178-187](../../scripts/plan/context_assembler.py) currently RAISES on any carried value matching `_RAW_GENOTYPE_PATTERNS` (`rs\d+`, `\([ACGTDI]+;[ACGTDI]+\)`, [router.py:192-195](../../scripts/plan/router.py) [VERIFIED]) — it would fail-closed on exactly the `(C;C)` / rsID data this decision carries. The DEFAULT rework is a SCOPED exemption: exempt ONLY the genetics read path, and KEEP the guard on every non-genetics carry (a genotype smuggled into `raw-nutrition-free-text` still fails closed). Blanket removal of the guard is a silent safety-property loss and requires explicit justification — out of scope by default (OQ-2).
- **Mechanism constraint to keep router.py frozen (OQ-1).** The `_HEALTH_SUBSTANCE_ALLOWLIST` field mechanism cannot carry genetics without breaking the load-time partition assert ([context_assembler.py:80-84](../../scripts/plan/context_assembler.py) [VERIFIED]), because `dna-report` is not a `router.EXCLUDED_RAW_PII` class; using the allowlist literally would force adding a genetics class to `EXCLUDED_RAW_PII` — a router.py edit that violates the "context_assembler.py only" scope. A separate `dna-report`-source read path avoids it.

**Neutral:**
- ADR-0032's derived `genetic-trait-classes` token, the variant-keyed library, `match_genotypes`, and the de-associated research lane all persist as the de-identified SUMMARY layer; only the raw-genotype-never-crosses invariant is reversed.
- `variants.py` trait-class widening (the prior draft's core work) is now OPTIONAL — the derived token stays for the summary, the raw genotypes are the personalization signal; widening the curated set is a nice-to-have, not required.
- Raw lab values and medications already crossing the assembler uncollapsed are now the INTENDED behavior under the reset identity-only standard, not a tension — the prior draft's lab-banding and medication reconciliations are moot.

### Alternatives Considered

#### Alternative A: Keep the derived `genetic-trait-classes` token only
Leave genetics reaching the specialist solely as ADR-0032's coarse 8-class token; personalize off the derived classes.
- **Supporting evidence:** Smallest genetic payload and strongest privacy posture — no raw genome leaves the machine, preserving the crown-jewel carve-out exactly as ADR-0032/0042 built it; the 8 classes are already gated and stable.
- **Trade-offs:** ~105 of 115 stored SNPs stay invisible to the author ([variants.py:10-28](../../scripts/genetics/variants.py), store `find` = 115 [VERIFIED]); the specialist cannot personalize off the panel the operator has data for. Rejected: the operator wants the full raw panel.
- **When this becomes the right choice:** If the genome's re-identification exposure is judged unacceptable (the "for now" revisit), retract to this — it is the standing retraction target.

#### Alternative B: Widen the derived trait-class MAPPING without raw genotypes
Extend `PLANNING_RELEVANT_VARIANTS` + author gated library findings so more stored SNPs map to de-identified functional classes (the prior ADR-0051 draft), never crossing a raw genotype.
- **Supporting evidence:** Reaches more of the panel while preserving the crown-jewel carve-out — no raw genome crosses; each class rests on a cited, ingestion-gated evidence basis; it is the more-conservative middle path.
- **Trade-offs:** It is still a lossy derived layer — a SNP not curated with a gated finding stays invisible, so coverage is a permanent per-SNP curation burden, and the signal is always the coarse class, never the raw call. The operator chose raw for completeness "for now" over this ceiling. Rejected on operator instruction.
- **When this becomes the right choice:** If the re-identification risk of the raw genome is later judged unacceptable, this is the privacy-preserving path back to richer-than-8-class coverage without the raw carry — the natural landing spot for the "for now" revisit.

#### Dissent: The genome-is-a-fingerprint purist position (inherited from ADR-0032 / 0042)
**Source:** ADR-0032's crown-jewel anchor that the raw rsID+allele genotype NEVER crosses, and ADR-0042's RT-008 genetics carve-out ([ADR-0032, Decision](ADR-0032-dna-aware-planning.md); [ADR-0042, Decision §2](ADR-0042-context-assembler-full-record.md) [VERIFIED]). A reviewer can reasonably hold that a genome is categorically different from other health substance — identity-stripping cannot anonymize a unique biometric fingerprint, so "identity-stripped raw genotypes" is not a de-identified payload in any meaningful sense, and the derived-classes path (Alternative B) is the only posture that honors the crown jewel.
**Conditions under which this becomes the right choice:** If the no-train lane's no-train / retention terms degrade (genetic payloads becoming training-eligible or long-retained), OR if the re-identification exposure is judged unacceptable on review — then retract the raw carve-out reversal to Alternative B / A (the operator's "for now" is the built-in revisit trigger).

### Validation Approach

**Confirmation criteria:**
- **The specialist payload carries the raw panel (executable):** seed a store with `dna-report` genotypes across the stored SNPs; run the plan path and assert the specialist input carries the raw rsID + allele calls (e.g. `MTNR1B rs10830963`→`(C;C)`) for the stored panel, not only the derived 8-class token. Threshold: ≥ the stored-genotype count MINUS the preserved sensitive-variant exclusions reaches the specialist; 0 non-excluded stored genotypes silently dropped.
- **The derived token still rides alongside (executable):** assert the assembled record ALSO carries the derived `genetic-trait-classes` token ([router.py:305](../../scripts/plan/router.py) [VERIFIED]) — the raw carry is additive, not a replacement.
- **A plan cites a raw-genotype-informed rec (executable):** with a fixture genotype, assert the rendered plan reflects ≥1 recommendation grounded in a raw genotype the derived 8-class token would not have carried.

**Falsification criteria:**
- **Identity-leak probe → FAIL (the new load-bearing probe):** seed a synthetic operator legal name, DOB, and contact string INTO a `dna-report` field, run the plan path, and scan every specialist payload. Threshold: **0 identity tokens** (name / DOB / contact / MRN / insurance-id / provider-name) in any specialist payload; ≥1 means the identity strip failed on the genetics carry — halt and repair before release. This REPLACES the prior raw-genotype probe (raw genotypes are now intended, not a leak).
- **Genotype-rejection-removed probe → FAIL:** run the genetics carry over a real `(C;C)` genotype; if the assembler RAISES the `_RAW_GENOTYPE_PATTERNS` rejection ([context_assembler.py:178-187](../../scripts/plan/context_assembler.py) [VERIFIED]), the backstop was not reworked and the raw carry is dead. Threshold: the genetics carry completes without the genotype-rejection raise for ≥1 genotype.
- **Sensitive-exclusion probe → FAIL:** seed the operator's DRD2 rs1800497 + BDNF rs6265 (and a fixture APOE rs429358) genotypes and run the plan path. Threshold: **0 raw APOE / DRD2 / BDNF genotypes** in any specialist payload (the exclusion default held); ≥1 means "identity-only" silently crossed the ADR-0032 sensitive set — halt (crossing them raw is a separate explicit operator call, OQ-3).
- **Frozen-surface probe → FAIL:** `git diff --numstat` on `router.py` and the ADR-0032 frozen inner-engine glob after the change. Threshold: **0 changed lines** in `router.py` (incl. `EXCLUDED_RAW_PII`, `SUMMARY_FIELD_SET`, the trait-classes deriver + backstop) and the frozen engine; a router.py edit means the carry mechanism forced an `EXCLUDED_RAW_PII` extension (OQ-1) — halt and re-mechanism to the `dna-report`-source read path.
- **Non-falsifiable residual (stated, not probed):** the genome's re-identification exposure is INHERENT and cannot be probed away — it is the accepted, revisitable Negative, not a test threshold.
- **Time horizon:** run the identity-leak, genotype-rejection-removed, sensitive-exclusion, and frozen-surface probes at the first build, at the operator-present LIVE run (OQ-4), and at every release thereafter, and before the July-2026 physician-visit deliverable.

**Review triggers:**
- ADR-0050 lands (the assembler is wired to the live author) — re-run the identity-leak probe on the live path and confirm the specialist prompt interprets rsID+allele calls.
- The no-train lane's no-train / retention terms change — re-verify the raw-genome egress is still acceptable (the Dissent / "for now" retraction condition — retract to Alternative B/A).
- Any operator re-evaluation of the re-identification exposure ("for now" expiry) — re-open the raw-vs-derived decision.
- The `pii_scan` identity token/value classes change — re-verify the genetics-payload identity coverage.
