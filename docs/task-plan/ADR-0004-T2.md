> `scripts/generate/render.py`, ordered by the `ADR-0004-T1 → ADR-0004-T2` dependency edge.

## Risk Pre-Check

The spec lists risk mitigations for this task (ADR-0004 Negative, ADR-0007 Negative, Constraint D1→ADR-0007); the Risk Pre-Check is active. Every gate below is a falsifiable RED target — a `assert True` / boolean / no-op placeholder FAILS the gate.

- **Risk: ADR-0004 Negative (inline-everything per-file size pressure — the most asset-heavy artifacts press against the <500KB budget) + ADR-0007 Negative (matrix/projection strain the budget).** Spec assigns criteria 1, 2, 4.
  - **Gate (crit 1 — <500KB worst-case):** a RED test MUST render the **most asset-heavy matrix+projection artifact over the ADR-0004-T0 spike dataset** through the production `render.emit` matrix/projection path, capture the returned file path, and assert `wc -c` over that file is **strictly < 500000 bytes** (assert the measured byte count < 500000, computed over a real render — not an estimate, not a boolean "fits"). A test over a trivial single-series render fails this gate; it must be the worst-case combined matrix + projection view.
  - **Gate (crit 2 — cap paginates over-cap → ≥2 files each <500KB):** a RED test MUST feed a dataset **above the ADR-0004-T0 cap** (exceeding the recorded max-rendered-timepoints-per-view OR max-series-per-view) and assert the render emits **at least 2 output files**, each strictly < 500000 bytes (`wc -c` on each returned path < 500000). A test that asserts a single over-budget file, or only checks the at-cap single-file path, fails this gate — the over-cap pagination/split direction is required.
  - **Gate (crit 4 — shared-defs appears exactly once):** a RED test MUST assert the **chart-component template id appears in the output's shared-defs block exactly once** (count == 1) and is REFERENCED per view, NOT duplicated per series (the markup is shared from `component_set.py`, not re-emitted per series). A test asserting "the chart renders" without counting the shared-defs occurrences fails this gate; the exactly-once count is the falsifiable target.
- **Constraint D1→ADR-0007 (no labs/answers to model: the matrix/projection recompute is local-only; the render path invokes no model step).** Spec assigns criterion 5.
  - **Gate (crit 5 — egress-0-call + 0 lab/answer to model):** a RED test MUST wrap a real matrix/projection `render.emit` call in ONE zero-arg closure under the ADR-0001-T1 egress guard (`egress_guard.run`) and assert `run` is **truthy** (0 outbound calls observed across the whole render), AND assert that 0 lab value / symptom answer appears in any model-bound dispatch — the render path makes NO model step at all (it reads the store and writes a local file). A test that asserts 0 calls over a no-op (rather than over a real matrix/projection `emit`) fails this gate; it must exercise the production render path. The SEC-03 failing-capable companion (a synthetic outbound call injected into the matrix/projection render path must drive `egress_guard.run` to FAIL / falsy) is the W4→5 boundary check (build plan line 251) — schedule it as a RED target alongside the happy-path egress assertion so the gate proves the guard actually intercepts this NEW render code path, not merely that a clean run makes 0 calls.

These gates are first-class RED targets, scheduled in the cycles below — not optional add-ons.
