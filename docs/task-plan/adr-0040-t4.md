## Risk Pre-Check

This task HAS risk mitigations in the spec — Risk Pre-Check is REQUIRED and is a **BLOCKING GATE**: T4 is a state-changing operator-confirm endpoint (a CSRF confirm/spend surface) AND the fail-closed release gate for the whole ADR-0040 hold. Each gate condition below MUST be satisfied by a concrete, failing-capable test in RED before any GREEN code (a `assert True` placeholder fails this gate):

- **Risk — SEC-0040-01 (CSRF/415 content-type gate on a state-changing confirm route):** a state-changing confirm route without the content-type gate is a CSRF confirm/spend surface. Gate: a test asserts `POST /confirm-plan-change` with `Content-Type: text/plain` — AND with NO `Content-Type` header — is refused **415 BEFORE any body parse** with the pointer **NOT flipped (0 mutation)**, mirroring `_do_confirm_extraction`'s gate. FAILING-CAPABLE: with the ctype gate dropped, a `text/plain` body carrying `{"domain":"workout","plan_date":<today>,"decision":"confirmed"}` flips the pointer, reddening the 0-mutation assertion (mirror `test_confirm_text_plain_rejected_415_no_land`). (Spec T4 AC-5, amended 2026-07-05.)
- **Risk — SEC-0040-02 (413 `Content-Length` ceiling):** an unbounded confirm body materializes in RAM. Gate: a test asserts an over-ceiling `Content-Length` (`> _CONFIRM_MAX_BYTES`) is refused **413 BEFORE the body is read**, 0 mutation — parity with `_do_confirm_extraction`'s ceiling, driven in-process for determinism (mirror `test_confirm_oversize_content_length_413_no_land`). (Spec T4 AC-5.)
- **Risk — ADR-0040 §5 fail-closed-on-decline (no unconfirmed plan ever stands):** a declined / unactioned large re-gen must NEVER resolve to the held plan. Gate: a test asserts that after `confirm_plan_change(domain, plan_date, "declined", root)` — OR leaving the pointer `pending` — `read_plan(domain, plan_date, root)` stays `NO_PLAN_TODAY` (plan `None`) indefinitely with 0 tailored artifact, and the unconfirmed `plan::<domain>` reading STAYS in append-only history (auditable, never standing). (Spec T4 AC-3.)
- **Risk — ADR-0040 OQ-7 / AR-008 (a past-dated held/confirmed plan renders as "today"):** a late confirm must have defined fail-closed semantics. Gate: a test asserts a `confirm_plan_change(domain, plan_date, "confirmed", root)` where `plan_date < today` is REFUSED past the staleness bound — the stale pending is GC'd (set `declined`), the domain re-enters the normal re-gen path, and `read_plan` reads `NO_PLAN_TODAY` for the stale date; the deferred `_post_promote_tailoring` keys on `plan_date` (not the confirm date), so no past-dated tailored section renders as the current day. (Spec T4 AC-4.)
- **Risk — QA T4-1 / Architect F1 (metered raw-egress double-spend on re-confirm):** `confirm_plan_change` re-fires `_post_promote_tailoring` → a metered `tailor_client.converse`; an artifact-content-only idempotency assertion PASSES a re-spend because `reemit_maintained` OVERWRITES the tailored block. Gate: a test asserts a SECOND `confirm_plan_change` of the same `(domain, plan_date)` short-circuits (decision already `confirmed`) and triggers 0 ADDITIONAL `converse` calls — **converse-count == 1 across two confirms**, measured at the MODEL-CALL level. FAILING-CAPABLE: without the transition short-circuit the second confirm re-fires `converse` (count == 2). (Spec T4 AC-2, amended 2026-07-05.)
- **Risk — Security F1 (decision-enum default-allow → raw-egress tailoring):** a two-branch `else: confirm` GREEN treats a present-but-invalid token as `confirmed` (an unvalidated flip stands → tailors → raw egress). Gate: an act-level test asserts `confirm_plan_change(domain, plan_date, "approved", root)` raises `ValueError`, leaves the pointer UNFLIPPED (`decision_for(...) == "pending"`), and fires 0 tailoring; a route-level test asserts a valid-JSON body carrying `decision:"approved"` returns **400** with the pointer UNFLIPPED. FAILING-CAPABLE: a default-allow `else` flips the pointer to `confirmed`, reddening both. (Spec T4 AC-1b + AC-5.)
