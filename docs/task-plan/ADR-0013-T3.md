# Recipe: Apple-Health-Zip → `export.xml` Extraction (Mirrors `dna.land`)

This task produces CODE: the `scripts/serve/apple_zip.py` module that accepts an uploaded
Apple Health export `.zip` and extracts its single `*/export.xml` member to a staged path the
existing streamed `iterparse` read can open — MIRRORING `dna.land`'s zip-member extraction
(`zipfile.is_zipfile` branch → locate the one member of interest → `zf.open(member)` streamed
copy). A pre-extracted raw `export.xml` passes through unchanged; a zip with no `export.xml`
fails loud. It PUBLISHES the extraction consumed by `ADR-0013-T4` (the route extracts before
routing the xml into `ingest.run` via the unchanged `healthkit` adapter). The extraction lives
ONLY in `scripts/serve/apple_zip.py` — `healthkit.py` / `ingest.py` / `dna.py` are BYTE-UNCHANGED
(the ADR-0013 0-extraction-in-ingest invariant + the ADR-0012 "streamed read is unchanged").
The TDD Steps follow the standard RED/GREEN/REFACTOR/REGRESSION cycle.

## Interface Contracts

This task PUBLISHES the extraction consumed by `ADR-0013-T4`, so the contract is load-bearing.

- **Function:** `extract_export_xml(staged_path, temp_root)` (or equivalent) in `scripts/serve/apple_zip.py` — **NAMED CONTRACT (frozen at this task):** if `staged_path` is a zip, returns the staged path of the extracted single `*/export.xml` member (streamed under the byte ceiling); if it is a raw xml, returns it unchanged; raises a stated error if a zip carries no `*/export.xml`. **Invariant (load-bearing for criterion 5):** the extraction lives ONLY in `apple_zip.py`; `healthkit.py` / `ingest.py` / `dna.py` are byte-unchanged. **Breaks if:** the extraction is added into the adapter/ingest layer — then criterion 5 (0-edit) and the ADR-0013 "server adds no extraction logic to the ingest layer" / ADR-0012 "streamed read is unchanged" invariant fail.
- **Dependent task:** `ADR-0013-T4` (the route calls `extract_export_xml` before routing the resulting xml into `ingest.run` via the unchanged `healthkit` adapter). **Change control:** `ADR-0013-T4` MUST NOT push the extraction into the ingest layer.
