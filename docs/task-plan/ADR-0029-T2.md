## Risk Pre-Check

This task carries the spec's ADR-0029-T2 Risk Mitigations field. Before proceeding to RED, verify a
test exists (or the RED phase adds one) for EACH; a placeholder test (`assert True`) fails this gate.
The gate conditions reference live tests/commands, not subjective assessments.

- **Risk — public-repo key/PII leak (MEMORY: no operator PII / API key in tracked text — the repo is
  PUBLIC).** A converse implementation that interpolates the SDK exception into the error message, or
  reads the key from a tracked file, or lands a key literal in the tree, is a key/PII-leak vector.
  Gate: (a) converse resolves the key ONLY at call time via `key_source.resolve` inside `self._client()`
  (no tracked-file read) — a test patches `key_source.resolve` to a sentinel and asserts the patched
  SDK was constructed with that sentinel (AC-2); (b) the tree-wide key-literal gate
  `tests/model/test_key_source.py::test_no_api_key_literal_in_tracked_tree` stays green (0 `sk-ant-…`
  literal in the tracked tree, AC-2); (c) on a failure whose SDK exception EMBEDS a synthetic raw-turn
  token + a synthetic key token, the raised `ModelCallError` carries 0 occurrences of either on
  `str()`/`.args` AND on the fully-rendered traceback (the `__cause__`/`__context__` chain is severed
  by `from None`) — count of token hits == 0 (AC-3).
- **Risk — fabricated turn / silently-partial payload (ADR-0015 fail-closed, NFR-2).** A converse that
  returns a fabricated or partial turn on a failed/empty/errored/timed-out call defeats the fail-closed
  contract. Gate: each failure mode injected at the patched SDK (`messages.create` returns nothing /
  raises / a malformed non-`{reply,extraction}` body / a bounded-retry exhaustion) makes converse RAISE
  `ModelCallError` with the CONSTANT message + `from None` — never a fabricated turn; the public
  `ModelClient.converse` validation ([:47-60]) additionally rejects a truthy-but-malformed body
  (count of fabricated payloads returned == 0) (AC-1, AC-3).
- **Risk — new outbound class / PII-boundary drift (ADR-0029 PII-boundary-unchanged, NFR-1).** Converse
  must join the EXISTING no-train lane, adding 0 new outbound class and changing no method but its own.
  Gate: `git diff scripts/model/client.py` shows the ONLY changed method body is
  `_ClaudeNoTrainBackend.converse`; `deidentify`, `author`, every `ModelClient.*` wrapper, `_client`,
  `_call`, and the constants are byte-unchanged (AC-5); the single-SDK-import boundary
  (`scripts/model/` only) holds — `tests/model/test_client.py::test_no_model_client_import_outside_the_seam`
  stays green.
- **Risk — live spend in CI (0-live-spend invariant).** A test that exercises the live SDK call spends
  real budget. Gate: every converse test injects the fixture SDK at the `_client` seam (the
  `_patch_backend_client` posture) OR leaves the seam UNPATCHED to prove the absent SDK raises
  `ModuleNotFoundError` BEFORE any network request (mirroring

## Interface Contracts

This task FULFILLS (does not change) the already-published `ModelClient.converse` contract by
implementing the default backend's `converse` — it CREATES no new shared interface and has no in-spec
dependency edge (the standalone Wave-1 entry point; its in-spec tests mock the backend at the seam).

- **`_ClaudeNoTrainBackend.converse(messages)` backend-method contract (the conformance T2 supplies).**
  - Input: `messages (list[dict])` — the conversation turns (`{"role", "content"}`), the same arg the
    public `ModelClient.converse(messages)` ([`client.py:47`](../../../scripts/model/client.py)) forwards.
  - Returns: `(dict) {"reply": str, "extraction": list}` — the assistant reply text + the structured
    extraction proposal — satisfying the public `ModelClient.converse` validation
    ([`client.py:47-60`](../../../scripts/model/client.py): `isinstance(result, dict)` + truthy
    `result.get("reply")` + `"extraction" in result`).
  - Fail-closed: a failed / empty / malformed / errored / timed-out call RAISES
    `ModelCallError("converse call failed") from None` (a CONSTANT message; the chain severed) — never a
    fabricated or partial turn (NFR-2 / ADR-0015).
  - Runtime key: the key is resolved at call time via `key_source.resolve` inside `self._client()`
    ([`client.py:194-199`](../../../scripts/model/client.py)) — never a tracked file, never a module-load
    capture.
  - **Consumers:** the published `ModelClient.converse` surface is consumed at runtime by
    `chat.dispatch_turn` (the served `/chat` per-turn dispatch) and is MOCKED at the backend seam by the
    ADR-0029-T5 conversation→usable-plan E2E (T5 injects a fixture backend at the ADR-0015 seam, so T5
    depends on the SEAM shape, not on this live SDK body). The live converse SDK call itself is exercised
    only at the operator-present LIVE run, out of scope here.
  - **Change control:** T2 PRESERVES the public `ModelClient.converse` signature + validation verbatim
    (AC-5). Any later task changing the published `{"reply", "extraction"}` contract — or the backend
    method's input/return/fail-closed shape — MUST go through Architect review (it is the surface
    `chat.dispatch_turn` + the T5 E2E bind to).
