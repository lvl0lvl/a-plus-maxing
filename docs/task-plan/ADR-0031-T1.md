# Recipe: Local PDF→Text Extraction Module — `pdftotext` Primary, `marker` Fallback on Low-Text, 0 Network, Fail-Loud (`scripts/ingest/pdf_extract.py`, NEW; Mock/Fixture-Tested; 0 Live Spend)

A Wave-1 entry task (one of three parallel primitives — T1 ∥ T2 ∥ T3). It adds a NEW LOCAL-EXTRACT FRONT MODULE, `scripts/ingest/pdf_extract.py`, onto the frozen ingest engine. The module turns an uploaded PDF into TEXT entirely on-device so the crown-jewel raw binary never leaves the machine: ADR-0031 keeps the raw PDF bytes LOCAL (they reach only the `pdftotext`/`marker` subprocess) where ADR-0030 sent the whole raw PDF off-device as a base64 `document` block. T1 builds ONLY the extractor; T4 (Wave 2) wires it into `route._extract_unrecognized`.

The module is two-tier:

1. **`pdf_extract.extract_text(pdf_path) -> str` — the public extractor.** Runs `pdftotext` (poppler) as a deterministic local subprocess (text-layer extraction, 0 network) as the primary tier. When `pdftotext` yields no/low text (a return shorter than the named `_LOW_TEXT_CHARS` threshold — the scanned / no-text-layer case), it falls back to the `marker_single` (marker-pdf) local subprocess exactly once and returns that text. On TOTAL failure (both tiers yield no/low usable text) it raises a typed `PdfExtractError` — it NEVER returns a silent `""` (the honest-data, no-silent-empty contract).
2. **The `pdftotext`/`marker` subprocess-runner helpers + `_LOW_TEXT_CHARS`** — small internal helpers that shell each binary (stdlib `subprocess` + `pathlib`) and the one named low-text threshold constant (OQ-2, named here so the trigger is one machine-diffable value, not a call-site literal).

The build is MOCK/FIXTURE-tested at 0 live spend, 0 network: the branching / fallback / fail-loud logic runs against STUBBED subprocess runners (always-run, deterministic — `marker_single` is ALWAYS stubbed, NEVER a real heavy run / model download), and the real-`pdftotext` round-trip runs against a synthetic NON-PII fixture PDF behind a `skipif shutil.which("pdftotext") is None` gate so a clone without poppler stays green. The module imports/uses NO outbound HTTP client and NO model-client SDK (the crown-jewel local-extractor-network property, proven by a source-grep). The OS-level egress-guard LIVE 0-network probe is OQ-1 (operator-gated, deferred); this task's crown-jewel form is the structural/mock one.

`scripts/ingest/pdf_extract.py` is a NEW FILE — the frozen ingest engine (`scripts/ingest/ingest.py`, `scripts/ingest/adapter.py`), every `scripts/plan/*.py`, and the `scripts/store/keying.py`/`store.py` sink are byte-unchanged (EXTEND-NOT-REBUILD, NFR-3). T1 edits no existing production file.
