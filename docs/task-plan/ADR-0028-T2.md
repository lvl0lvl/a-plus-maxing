# Recipe: REAUTHOR/ADJUDICATOR Throw/Replay-Memo Mechanism (BaseException Sentinel + Fresh-Scratch Replay)

Invert the LAST two agent-touching dispatch classes — REAUTHOR (the energy-bounce re-author) and
ADJUDICATOR (the held-finding medical-liaison) — that fire DEEP INSIDE the byte-frozen
`orchestrate.generate_plans` and therefore CANNOT yield without editing the engine. T1 already
inverted AUTHOR + GATE by DIRECT YIELD in `drive`'s frame; these two cannot reach `drive`'s frame
that way, so they invert by THROW/REPLAY-MEMOIZATION: the consumer supplies memo-cache-backed
`reauthor`/`adjudicator` callables that, on a cache MISS, raise a `BaseException`-subclass sentinel.
The sentinel unwinds THROUGH the frozen engine (the engine's only catch is the narrow
`except ModelCallError` at [generate_plan.py:363](../../../../scripts/plan/generate_plan.py); it has NO
broad `except Exception`/`except BaseException`/bare `except:`) up to `drive`, which catches it,
yields the typed `REAUTHOR`/`ADJUDICATOR` request, caches the `.send()`'d envelope, and RE-DRIVES the
pass from the top over a FRESH scratch store. On a replay the same hook keys are now cached, so the
callable returns the envelope and the engine proceeds unchanged. The cap charges ONCE PER CACHE-MISS
(the existing `_charging` wrap, [plan_orchestrator.py:212-214](../../../../scripts/plan/plan_orchestrator.py)),
never on a replayed HIT.

The inner engine stays BYTE-FROZEN (numstat=0): `generate_plans` still calls `reauthor("workout",
{...})` ([orchestrate.py:550](../../../../scripts/plan/orchestrate.py)) and
`_adjudicate_with_band(safety_finding, adjudicator)` ([orchestrate.py:578,595,613](../../../../scripts/plan/orchestrate.py))
exactly as today — plain callables. The memo/replay logic lives ENTIRELY in `plan_driver.py` (the
sentinel catch + the fresh-scratch re-drive) + `plan_orchestrator.py` (the memo-cache callables +
charge-on-miss). The adjudication RELEASE (`outcome == "cleared"` + the CRITICAL/H1-H2
non-overridable check, [orchestrate.py:579,597,615](../../../../scripts/plan/orchestrate.py)) stays in
the inner engine's `adjudicate` — the consumer/driver returns ONLY the raw liaison envelope, never
re-derives the release (the no-fork crown jewel, this wave's consumer axis).

**Build dependency (load-bearing): depends-on = ADR-0028-T1.** T2 is built on the T1 branch (atop the
typed discriminated-union request protocol + the per-class consumer switch). The `<base>` for every
numstat probe in this recipe is the T2 wave-base — `git merge-base HEAD <T1-branch>` — not `main`.
T1 must have RAN green at its Wave-1 checkpoint (the typed-request protocol emits AUTHOR+GATE tagged
requests; the GATE composes via `compose_gate_dispatch`) before T2 builds; this recipe extends that
wire shape with the REAUTHOR + ADJUDICATOR request kinds and adds the sentinel/replay catch.

## Risk Pre-Check

This task carries the spec's ADR-0028-T2 Risk Mitigations field. Before proceeding to RED, verify a
test exists (or the RED phase adds one) for EACH; a placeholder test (`assert True`) fails this gate.
The gate conditions reference live tests/greps, not subjective assessments.

- **Risk N3 — the replay machinery has a resumable-state / idempotent-replay correctness burden
  (ADR-0028 Consequence-Negative-3): a fresh-scratch re-drive could double-charge the budget or
  double-write the promote.** Gate (REPLAY SAFETY): a fixture run triggering ≥1 REAUTHOR + ≥2
  ADJUDICATOR dispatches (multiple replay rounds) → `budget.count` AND the promoted-store row-count
  EQUAL those of a single synchronous in-process `run_orchestrated` drive of the same fixtures (exact
  equality). `budget.count` exceeding the reference (a HIT was charged) OR the row-count exceeding it
  (a replay double-promoted) → FAIL (AC-7). Paired with the cache-HIT-raises-no-sentinel gate (AC-3).
- **Risk — the sentinel is silently swallowed by `_safe_gate`'s `except Exception` or any future
  broad engine catch (the `BaseException`-vs-`Exception` choice).** Gate: the sentinel is a
  `BaseException` subclass — `issubclass(<sentinel>, BaseException) and not issubclass(<sentinel>,
  Exception)` — AND a direct test that `_safe_gate` / a `try/except Exception` around `run_generation`
  does NOT catch it (it unwinds to `drive`'s handler) (AC-8). The live `_safe_gate` guard
  (`except DispatchCapExceeded: raise` then `except Exception: return None`, [plan_driver.py:188-193])
  is the proof site.
- **Risk — fail-closed must hold in TWO distinct PER-DOMAIN-HOLD shapes, not one terminal shape
  (ADR-0028 OQ-3).** Gate (REAUTHOR): a malformed/absent/raised re-author envelope (no
  `reconciliation.energy_cost_kcal`, or `None`, or over-ceiling) → the WORKOUT domain stays HELD
  (`ENERGY_BOUNCE_UNRESOLVED`, [orchestrate.py:565], records nothing) while other domains MAY surface
  — threshold "workout not recorded", NOT "0 plans" (AC-5). Gate (ADJUDICATOR): a malformed/absent/
  raised liaison envelope for a held domain → that AFFECTED held domain stays HELD (the
  `outcome == "cleared"` release does NOT fire) while other domains MAY surface — threshold "affected
  domain not recorded", NOT "0 plans" (AC-6).
- **Risk — frozen inner engine re-authored (ADR-0028 OQ-4 / EXTEND-NOT-REBUILD).** Gate (a SHELL
  gate, `<base>` = `git merge-base HEAD <T1-branch>`, unresolvable inside pytest):
  `git diff --numstat <base>..HEAD` on the 8 inner-engine files → 0 changed lines. A STANDING
  INVARIANT verified in REGRESSION + at the Wave-2 checkpoint, not a RED-first test (AC-4).
- **Risk — NO-FORK at the consumer: building the adjudicator memo-fulfilment re-derives the
  adjudication RELEASE (the ADR-0028 no-fork validation gate, this wave's consumer axis).** Gate: a
  grep over `scripts/plan/plan_orchestrator.py` AND `scripts/plan/plan_driver.py` for a re-derivation
  of the adjudication release (`outcome == "cleared"`, the CRITICAL/H1-H2 non-overridable check) finds
  0 — the consumer returns ONLY the raw liaison envelope; the engine's `adjudicate` composes the
  release. (Folded into AC-6's verification + a dedicated release-grep test.)

## Interface Contracts

This task EXTENDS the `plan_driver` drive-protocol (created by ADR-0026-T1, extended to typed requests
by ADR-0028-T1) with two new request kinds, and ADDS the memo-cache fulfilment contract the consumer
(`run_orchestrated`) and the downstream step-harness (ADR-0028-T3) drive. It PRESERVES the inner
engine's hook-call shape (`reauthor(domain, constraint)` / `adjudicator(safety_finding)`) verbatim.

- **The replay sentinel (`BaseException` subclass — NEW, consumed by `drive`'s catch + ADR-0028-T3's
  harness).** A `BaseException`-subclass exception (NOT `Exception`) carrying the dispatch CLASS
  (`REAUTHOR` / `ADJUDICATOR`) + the memo KEY it was raised for. Raised by the consumer's memo-cache
  callable on a cache MISS; caught ONLY by `drive`'s replay handler (never by the engine's
  `except ModelCallError`, never by `_safe_gate`'s `except Exception`). It must NOT be re-typed to
  `Exception` by any downstream task without Architect review (the non-swallowable property rests on
  the `BaseException` base).
- **The memo-cache fulfilment contract (NEW, consumed by ADR-0028-T3's harness serialization).** The
  consumer supplies `reauthor`/`adjudicator` callables backed by a memo cache keyed
  `reauthor:(domain, constraint)` / `adjudicator:(held-domain, hold-class, finding_id)`. On HIT →
  return the cached envelope (engine proceeds unchanged); on MISS → raise the sentinel + charge the
  budget once. The KEY SHAPES are the format ADR-0028-T3's `plan_step.py` serializes (T3 AC-2
  round-trips exactly these two shapes) — a downstream task changing the key shape MUST coordinate with
  T3's serialization (Architect review per Core Rule 10).
- **`drive`'s extended yield protocol (the typed request union — EXTENDED).** `drive` now also yields
  `REAUTHOR` / `ADJUDICATOR` typed requests (in addition to T1's `AUTHOR` / `GATE`), each fulfilled by
  the consumer's `.send()` of the dispatched envelope. The consumer's per-class `kind` switch (T1)
  gains the two new arms. The fail-closed shapes are PER-DOMAIN holds (REAUTHOR → workout held;
  ADJUDICATOR → affected domain held), NOT the terminal `SAFETY_BLOCKED` (which is the GATE class's
  shape, T1). Downstream tasks (ADR-0028-T3 harness drive, ADR-0028-T4 skill drive, ADR-0028-T5 replay
  E2E) MUST NOT change this protocol (the request kinds, the per-domain-hold fail-closed shapes, the
  charge-on-miss-only accrual, the release-stays-in-engine no-fork) without Architect review.
- **The adjudication RELEASE stays in `orchestrate.adjudicate` (PRESERVED, no-fork).** The consumer's
  adjudicator memo-callable returns ONLY the raw liaison envelope; the `outcome == "cleared"` +
  CRITICAL/H1-H2 non-overridable check ([orchestrate.py:579,597,615]) is NOT re-derived in
  `plan_orchestrator.py` / `plan_driver.py`. This is a STANDING no-fork invariant verified by the
  consumer release-grep (AC-6 / Cycle-1 release-grep).
