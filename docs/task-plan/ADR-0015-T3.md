# Recipe: Wire the Plan-Author Dispatch Through the One Client (H-1, Honest No-Plan on Failure)

This task produces CODE: it re-wires `scripts/plan/generate_plan.py`'s `_author_callable` so the
plan-author envelope is produced by a programmatic call through `scripts/model/client.py`'s
`author(domain, summary)` — the ADR-0015 H-1 seam (the production seam is `_author_callable`'s
captured-envelope feed, [generate_plan.py:65-81](../../scripts/plan/generate_plan.py#L65) [VERIFIED],
NOT `router.dispatch`, which has 0 production callers). The plan-author is the SECOND consumer of
the one client (the first is `ADR-0016-T1`'s `/chat` conversation). `assemble`'s four safety filters,
the clearance gate, the per-domain translators, and `record_plan` are UNCHANGED — ADR-0015 amends
ONLY ADR-0006's dispatch MECHANISM. The author call carries the de-identified `router.summarize`
summary (this path is summary-only — NOT the `/chat` raw-egress carve-out). A FAILED author call
yields the honest no-plan state (`recorded == False`), NEVER a fabricated or degraded plan. Built +
tested against a MOCK client at the seam (a deterministic fake `author`, no live agent dispatch, no
live API). The TDD Steps follow the standard RED/GREEN/REFACTOR/REGRESSION cycle.
