# Recipe: The Uniform Seven-Field DOMAIN PROGRAM Schema + Conformance Validator

> Wave-1 entry-point task (Dependencies: None). It creates the uniform seven-field DOMAIN
> PROGRAM contract (`scripts/plan/domain_program.py`) + its conformance `validate()` — THE
> schema every downstream comprehensive-plan consumer emits against or reads: ADR-0041-T2's
> migrated translators emit programs that must pass `validate`, ADR-0044-T1 stores the seven-field
> program intact in the comprehensive model, ADR-0043-T2 reconciles its `cross_domain_seams` edge
> shape, ADR-0045-T1 compiles its `monitoring_signals` + `adjustment_rules`, and ADR-0046-T1's
> dispatched specialists all emit the uniform shape. This is a GREENFIELD module — it makes NO
> frozen-spine edit; the frozen four (`store.py` / `keying.py` / `pipeline.py` / `adjudicate.py`)
> stay byte-frozen (an entry-state `numstat=0` check only, never read). The load-bearing property
> is FAIL-CLOSED conformance: an under-delivered program (a missing required field, a compound
> program with no autoregulation, a monitoring signal with no validity tier, a program with no
> recognized domain KIND) is REJECTED — an honest no-plan state, never a degraded static plan
> (ADR-0041 Consequences-Negative-4). The seven fields = required `{prescription, rationale,
> monitoring_signals, adjustment_rules}` + conditional `{required_labs (empty-OK pure-training /
> mandatory-and-non-empty compound), refusal/escalation, cross_domain_seams}`. Each program ALSO
> declares a domain KIND — a token from the closed `DOMAIN_KINDS` vocabulary (a program-identity
> attribute distinct from the seven content fields) that keys the required-vs-conditional table;
> `validate` FAIL-CLOSES on an absent or unrecognized kind, so an unclassifiable program can never
> silently escape the compound-only floors (`required_labs`, autoregulation).

## Interface Contracts

This task CREATES `scripts/plan/domain_program.py` — THE uniform schema every downstream comprehensive-plan task emits against or reads. The contract is the shared seam:

- `domain_program.validate(program: Mapping) -> None` — `program` is a mapping (a `dict`, per the mirrored `test_adjudicate.py` dict-builder convention). Raises `domain_program.DomainProgramError` on a non-conformant program; returns `None` on conformance. Fail-closed: an incomplete/under-delivered program is rejected, never returned in a degraded form.
- `domain_program.missing_required_fields(program: Mapping) -> list[str]` — the required-field names absent from `program` (empty list == conformant on the required-field axis); a non-raising conformance probe for consumers.
- `domain_program.DomainProgramError` — the single typed rejection channel. Carries STRUCTURED offense accessors: `.offending_field: str` (the field/attribute at fault — a required field name, the kind attribute, `required_labs`, `monitoring_signals`, or `adjustment_rules`) and `.offending_signal` (the offending `monitoring_signals` entry for a per-signal tier offense; `None` otherwise). A caller identifies the offense STRUCTURALLY, not by substring-scanning the message.
- **The seven-field shape** — required `{prescription, rationale, monitoring_signals, adjustment_rules}` + conditional `{required_labs, refusal/escalation, cross_domain_seams}`, exposed as module constants. Uniform across EVERY domain.
