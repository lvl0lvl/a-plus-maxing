# Recipe: Non-Tautological Self-Test / E2E Extension — REAUTHOR + ADJUDICATOR Replay Paths

Extend the A′-inversion self-test (`scripts/plan/_a_prime_self_test.py`, Modify) + its test
(`tests/plan/test_a_prime_self_test.py`, Modify) so the self-test/E2E NON-TAUTOLOGICALLY exercises the
REAUTHOR + ADJUDICATOR throw/replay paths (T2's `BaseException`-sentinel → yield → `.send()` → fresh-scratch
replay). The current `_sustaining_authors` fixture ([_a_prime_self_test.py:211-226]) is sustaining
(workout `energy_cost_kcal: 500` < nutrition `sustainable_training_kcal: 700`, `sustains: True` → NO
energy bounce) and `_finding_dispatch` ([:136-151]) emits a `medical-safety-reviewer` SAFETY-review
finding (which drives the gate's `safety_passed` not-True — NOT an additive-AE/conflict/Rx-BPMH hold that
fires `adjudicator`), so the existing self-test yields 0 REAUTHOR + 0 ADJUDICATOR. This task adds (a) a
NON-sustaining author set (workout `reconciliation.energy_cost_kcal` > the nutrition `energy_budget`
ceiling, `sustains: False`) → a real energy bounce ([orchestrate.py:382-390,547-565]) → a REAUTHOR yield;
and (b) a held-finding author set (an author-declared cross-domain conflict via
`reconciliation.conflicts`) → the declaring domain enters `conflict_held` ([orchestrate.py:413-418]) → with
an `adjudicator` hook wired, `_adjudicate_with_band` fires ([orchestrate.py:595]) → an ADJUDICATOR yield.

The LOAD-BEARING property is NON-TAUTOLOGY (AR-002 / PF-S63-02 / INV-CORE-CAPABILITY): the new fixtures
yield ≥1 REAUTHOR + ≥1 ADJUDICATOR while the existing `_sustaining_authors` fixture yields 0 of each — and
the test is RED-CAPABLE: it FAILS if the throw/replay path (T2) is removed (a driver that swallows the
sentinel / never yields the REAUTHOR/ADJUDICATOR classes makes the ≥1 assertion fail). That contrast (new
fixtures ≥1, sustaining 0) is the proof the replay path is actually EXERCISED end-to-end, not asserted
vacuously. The existing A′-inversion gates (promotion-on-accept AC-3 + 0-plans-on-safety-not-True AC-4 +
the `--self-test` non-zero-exit failure signal) are PRESERVED — this extends the self-test, it does not
rewrite the existing legs.

**Why the cross-domain conflict for the ADJUDICATOR trigger (SE's call — stated assumption):** the spec
File Manifest names "an additive-AE / cross-domain-conflict / Rx-BPMH hold" for the held-finding fixture
(any of the three fires the SAME `_adjudicate_with_band` gate, [orchestrate.py:576-616]). This recipe
ASSUMES the CROSS-DOMAIN CONFLICT axis: it is the simplest deterministic single-domain trigger — an author
envelope carrying `reconciliation.conflicts = [{"with": <compound>, "with_domain": <domain>, "reason":
...}]` holds the DECLARING domain ([orchestrate.py:413-418]) with no second compound candidate and no
operator-Rx-class store seeding. The additive-AE axis ([:426-435]) requires BOTH a supplements AND a
peptides candidate carrying a plan with a shared AE class; the Rx-BPMH axis ([:446-453]) requires seeding
the operator's present Rx-interaction classes into the store. The conflict axis needs neither, so it is the
minimal fixture that fires exactly one ADJUDICATOR round. (Same gate, simpler fixture; per Ask-vs-Proceed
step 3 — same interface, simpler implementation — stated, proceed. All three axes reuse the SAME gate, so
this loses no coverage of the adjudicator yield class.)

This task modifies `scripts/plan/_a_prime_self_test.py` + `tests/plan/test_a_prime_self_test.py` — NO other
file. It touches NO inner-engine module (numstat = 0): it adds fixtures + replay-leg drivers + a memo-cache
`reauthor`/`adjudicator` fulfilment, driving the EXISTING T1 typed-request protocol + T2 throw/replay
mechanism (built upstream) over the orchestrator/harness fixture seam — `generate_plans` still calls
`reauthor(...)`/`adjudicator(...)` exactly as today. Deterministic, runs under `.venv`, 0 live spend; the
fixtures are synthetic PII-free band/class tokens (0 raw operator PII). The live subscription dispatch is
the S94 operator-present attestation, out of scope (the self-test uses a fixture `dispatch`/memo cache,
never the live backend). T5 is ∥ T4 in Wave 4 with a DISJOINT file manifest (T4 = SKILL.md + value-scan +
glue test; T5 = self-test + its test) — no intra-wave collision.

## Risk Pre-Check

guard must prove the spine is wired NON-TAUTOLOGICALLY; AR-002: the build-blocking non-tautological
reauthor/adjudicator exercise; ADR-0028 Consequence-Negative-3: the replay machinery's correctness
exercised end-to-end on fixtures). Before proceeding to RED, verify a test exists (or the RED phase adds
one) for EACH; a placeholder test (`assert True`) fails this gate.

  replay leg "ran" without proving the replay path is exercised).** Gate (RED-CAPABLE): a test asserts the
  new non-sustaining-author fixture yields ≥1 REAUTHOR (AC-1) AND the new held-finding fixture yields ≥1

  classes; the assertion is NOT satisfiable by the pre-existing sustaining fixtures).

  correctness is unexercised end-to-end on fixtures.** Gate: a test asserts each replay round advances
  exactly one new cache-MISS dispatch (AC-3 — one new memo-cache entry per round until no miss remains) AND

  promotion-on-accept (AC-3-of-T4) + 0-plans-on-safety-not-True (AC-4-of-T4) + the `--self-test` non-zero
