# Recipe: Port `app.html` into a Tracked Inline-Asset Render-View + Re-point GET `/` + Honest Awaiting-States

The Wave-1 entry task and the served surface every downstream ADR-0029 task drives. Today the operator-approved
four-screen SPA lives ONLY in the gitignored `prototype/app.html` (a left-nav shell `Dashboard` / `Upload Documents`
/ `Plan` / `Chat with Team`, `<title>A+ Maxing</title>` at [app.html:2]); the served GET `/` body is still the intake
WIZARD, rendered by `generate.run("intake")` via `_render_intake` ([server.py:70], the hardcoded source at [server.py:81]).
This task does FOUR things atomically:

1. **Port the SPA into a TRACKED render-view module.** Create `vault/design/templates/app_shell.py` exposing
   `render(store_read, *, status=None, _today=None)` → the self-contained four-screen SPA HTML, registered as
   `generate.run("app")` in `scripts/generate/generate.py`'s `_TEMPLATES` ([generate.py:27]).
2. **Vendor every off-file asset inline.** The lucide CDN `<script src="https://unpkg.com/lucide@latest/...">`
   ([app.html:411]) is removed (icons rendered as inline `<svg>`, OQ-2 extract-used-icons preferred); the bare-path
   `<img src="images/body.png">` ([app.html:292]) is removed-with-its-awaiting-state or inlined as a `data:` URI — so
   `render.emit` over `app_shell.render` RETURNS a written `Path` rather than RAISING `ValueError`. This is the
   AUTHORITATIVE inline-asset check (render.py `emit` returns `(Path)` on success, `raises ValueError` + writes nothing
   on any external reference, [render.py:149,176]), NOT a substring grep.
3. **Render honest awaiting-states.** The `Dashboard`/`Plan`/`Chat with Team` screens present 0 fabricated operator data
   (no "Synced from WHOOP", the `84`% RECOVERY ring, `7.8` SLEEP, `2,650` kcal, `BPC-157 · 250mcg`, "Upper Push —
   Hypertrophy" presented as the operator's readings/plan, [app.html:290,295-296,342-345]) — each an awaiting/empty
   state (ADR-0009 D2). T3 (Wave 2) then wires the `Upload Documents` form/chat into the same module; T1 stands up the
   served surface only.
4. **Re-point GET `/` + migrate the dead-wizard tests.** `_render_intake`'s body source goes `generate.run("intake")` →
   `generate.run("app")` ([server.py:81]); the bind `_LOOPBACK="127.0.0.1"` ([server.py:29]) + the route table {GET `/`,
   POST `/upload`, POST `/chat`} stay byte-unchanged. The 19 `WIZARD_TITLE` assertion sites in `tests/serve/test_server.py`
   (constant def [test_server.py:34] + 19 assertions, GROUNDED `rg -c "WIZARD_TITLE"` → **20** total matches) are
   re-pointed (generic thread-survival sites → a SPA served-body marker) or REWRITTEN/RETIRED (the wizard-presentation-
   specific re-render tests) — NEVER a marker swap (no tautological dead-wizard test).

The byte-frozen INNER ENGINE (`scripts/plan/{orchestrate,pipeline,assemble,generate_plan,adjudicate,adjust,track,router}.py`
+ `deid_in.py`) stays numstat=0 (EXTEND-NOT-REBUILD); T1 touches only `app_shell.py` (new) + `generate.py` + `server.py`
+ the two test files. The build is MOCK/FIXTURE-tested at 0 live spend (no live API, no key, no non-loopback socket).
