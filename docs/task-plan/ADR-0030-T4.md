A Wave-4 leaf task: wire the operator-confirm surface into the EXISTING operator-approved Clinical-Light-LOCKED SPA. This task does TWO things, both in the SPA design source `vault/design/templates/app_view.html` (which `app_shell.render` reads VERBATIM via `_VIEW.read_text()`, [app_shell.py:104], so the served GET `/` body via `generate.run("app")` → `server.py:_render_intake` [:88] carries the edits):

The byte-frozen ingest engine (`scripts/ingest/{ingest,adapter}.py`) + every `scripts/plan/*.py` (incl. `deid_in.py`) stays numstat=0 (EXTEND-NOT-REBUILD, NFR-4) — T4 touches only `app_view.html` (markup + inline JS) + `tests/serve/test_app_shell.py`. The build is the rendered-SPA-HTML string + the standalone `app_shell.render` — MOCK/fixture-tested at 0 live spend (no live API, no key, no non-loopback socket).
