## Interface Contracts

This task does not change any function signature — `_do_generate_plan`, `self.client.author(domain, summary)`, and `assemble_context(store_read)` keep their existing signatures. It changes a BEHAVIORAL contract: the front-door author INPUT at both sites becomes `context_assembler.assemble_context(store_read)`'s identity-stripped record instead of the `router.summarize` band.

- **Consumed by:** ADR-0051-T1 (per the spec Dependency Map: `ADR-0050-T1 → ADR-0051-T1`). ADR-0051-T1 AC-6 (the Wave-2 end-to-end composition gate) drives `_do_generate_plan` with a spy `self.client` and asserts the seeded raw `<GENE> <rsID>=(X;Y)` genotypes reach the captured author payload — which holds ONLY because this task repointed the author input to the assembler's record. Until this task lands, ADR-0051-T1's carried genotypes never reach the model.
- **Change control:** a downstream task MUST NOT re-point the front-door author input back to `router.summarize`'s band without Architect review — doing so silently reverts the wiring (the exact regression AC-2 guards) and breaks ADR-0051-T1 AC-6.
- **Co-breakage note (ADR-0050-T2, not a dependency edge):** reverting this task's wiring also decoheres ADR-0050-T2's rewritten `_author_system_prompt`, which describes the input as the identity-stripped FULL record — it would then claim a record the author never receives. This is spec-faithful with NO T1→T2 dependency edge (both are Wave-1 entry points, file-disjoint): the Wave-1 co-landing makes the mismatch runtime-moot, observable only at the Phase-1 operator-present LIVE run. Recorded as a co-breakage note, not a new dependency.
