# Recipe: The Swappable No-Train Model Client + Runtime Key Source (Single Model Boundary)

This task produces CODE: the `scripts/model/` package — the system's FIRST programmatic model
boundary. It creates `client.py` (a swappable no-train model client with a two-method public
interface `converse(...)` / `author(domain, summary)`, default a Claude no-train commercial API,
swappable at the seam, fail-closed on a failed/empty/errored/timed-out call), `key_source.py`
(the injectable RUNTIME key source — env var / macOS-keychain `security find-generic-password`
command, fail-loud on absent, NEVER a tracked file), the package marker `__init__.py`, and the
operator runbook `keychain-setup.md`. It PUBLISHES the two-method client surface consumed by
`ADR-0016-T1` (`converse`), `ADR-0015-T3` (`author`), and `ADR-0017-T1` (validates `converse`'s
extraction-proposal output). It is the entry point — every model-touching task routes through it.
This is a single-import-point boundary: an `rg` over `scripts/` for any model-client import
(`anthropic`/`openai`/`.messages.create`/`httpx`/`requests`) must find them ONLY inside
`scripts/model/`, against today's baseline of 0 anywhere [VERIFIED]. The client is built + tested
against a MOCK backend (a fake backend returning fixtures) — no live API, no key. The TDD Steps
follow the standard RED/GREEN/REFACTOR/REGRESSION cycle.

## Risk Pre-Check

This task carries risk mitigations in the spec → Risk Pre-Check is active. Each gate maps to a concrete `pytest` test or `rg` assertion that must exist in the RED phase and fails if the mitigation is absent. A placeholder (`assert True`) fails each gate.

- **ADR-0015 Negative-1 (first hard commercial-API dependency) + Negative-2 (the swap seam ossifies if shaped to one provider).** Mitigation: criteria 2, 3 — the two-method boundary + the ≤1-file swap. **Gate (swap-clean, falsifiable):** a RED test constructs the client with an INJECTED alternate backend (the seam parameter) and exercises both `converse` and `author`, asserting 0 edits to either caller (`scripts/serve/chat.py`, `scripts/plan/generate_plan.py`) are needed to swap the provider. **Falsifiable RED:** the test turns RED if the swap requires a caller-side edit (the backend is hard-wired, not injectable). **Negative-control failing-capability proof:** the RED includes a one-time negative control — temporarily hard-wire the default backend so the seam parameter is ignored, confirm the swap-clean assertion FAILS (the injected alternate is not used), then revert to the injectable seam and confirm it passes.
- **ADR-0015 fail-closed contract (NFR-2).** Mitigation: criterion 4. **Gate (typed-raise-on-failure, falsifiable):** a RED test injects EACH failure mode (failed / empty / errored / timed-out) into the mock backend and asserts the method raises a TYPED failure, AND asserts the method NEVER returns a partial/fabricated payload. **Falsifiable RED:** the assertion turns RED if a failure mode returns a fabricated/silently-partial result instead of raising. **Negative-control:** temporarily make one failure mode return a fabricated payload, confirm the typed-raise assertion FAILS, then revert and confirm it raises.
- **Public-repo key leak (MEMORY: no operator PII / secret in tracked text — the repo is PUBLIC).** Mitigation: criterion 5. **Gate (key-never-tracked, falsifiable):** a RED test asserts `key_source.resolve()` reads a SET env var / runs the keychain-fetch command at call time, an UNSET key raises fail-loud naming how to set it, and `key_source` reads NO tracked file; AND a grep test asserts 0 API-key literal in the tracked tree (`rg -n "sk-ant-|sk-[A-Za-z0-9]{20,}" -- . ':!*.venv*'` returns 0). **Falsifiable RED:** the grep test turns RED if a key literal is in the tracked tree; the absent-key test turns RED if an unset key silently returns a default instead of raising.

## Interface Contracts

This task PUBLISHES the single model boundary — the two-method client + the runtime key source — consumed by `ADR-0016-T1`, `ADR-0015-T3`, and `ADR-0017-T1`, so the contract is load-bearing.

- **Client:** the model client in `scripts/model/client.py` — **NAMED CONTRACT (frozen at this task):** a two-method public interface. `converse(...)` → one intake turn: assistant reply text + a structured extraction proposal (the input `ADR-0017-T1`'s `extract_facts` validates). `author(domain, summary)` → the plan-author envelope `{"specialist": slug, "recommendations": [...]}` or the thin-library sentinel `{"thin_library": True, "specialist": slug}` (the shape `assemble`/`_author_callable` consume, [generate_plan.py:37](../../scripts/plan/generate_plan.py#L37)). **Invariants (load-bearing):** (a) the BACKEND is an injectable seam parameter — swapping the provider edits ≤1 file outside `scripts/model/` (AC-3); (b) a failed/empty/errored/timed-out call RAISES typed, never returns a fabricated/partial payload (AC-4, NFR-2); (c) the model-client import (`anthropic`/etc.) lives ONLY inside `scripts/model/` (AC-1). **Breaks if:** a caller-side edit is needed to swap the provider (the seam ossified), or a model-client import lands outside `scripts/model/` (the single-egress-class boundary the `/chat` seam rests on, `ADR-0016-T1`).
- **Key source:** `key_source.resolve()` in `scripts/model/key_source.py` — **NAMED CONTRACT:** resolves the no-train API key at RUNTIME from an env var / a macOS-keychain command; fail-loud on absent; reads NO tracked file. **Invariant (load-bearing, NFR-3):** no API-key literal is ever in the tracked tree (the repo is PUBLIC). **Dependent:** the client's default backend calls `resolve()` at call time; the LIVE end-to-end run (Wave-B operator checkpoint) is gated on the operator having stored the key per `keychain-setup.md`.
