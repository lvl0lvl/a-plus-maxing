# Recipe: Unified Maintained-HTML Output (Re-Emit + Folded Tracking)

This task creates the unified MAINTAINED HTML output lifecycle (`scripts/generate/maintained.py`) that AMENDS — does not replace — ADR-0004's on-demand single-file render (`generate.run`). It RE-EMITS one living plan artifact as new wearable/lab data arrives, preserving prior content (annotations, tracking history) across re-emits, folds the `track.resolve_plan_progress` plan-vs-actual MEASURE-leg view into the same format as a section, writes the PII-bearing artifact only to the gitignored `vault/artifacts/generated/`, and runs the format-then-fill order: the maintained render (`render.emit`) runs FIRST, then ADR-0021's deterministic `reinsert_out` is the FINAL local pass over the produced HTML. It is a STORE-SURFACE task — it reads the store via `track.resolve_plan_progress` and writes the store via `track.record_tracking` — so the store-adversarial battery (bead `pka`, `docs/checklists/store-adversarial-tests.md`) applies as a Tier-1 self-check AND a Tier-2 QA gate.

It WRAPS the existing engine verbatim (EXTEND-NOT-REBUILD): it re-authors neither `render.emit` (the re-emit primitive) nor `reinsert_out` (the OUT pass) nor `track` (the store read/write surface). Both `render.py` and `reinsert_out.py` are **Modify-or-use-only** — confirmed used, never edited.

## Risk Pre-Check

The spec's `### ADR-0025-T1` Risk Mitigations field is non-empty; each mitigation below maps to a failing-capable gate that MUST have a covering RED test before GREEN. A placeholder (`assert True`) fails every gate.

- **Risk R1 — maintained-artifact STATE: staleness / partial-update / store-divergence (ADR-0025 Consequence-Negative-1).** A maintained artifact can sit mid-re-emit or diverge from the store if a re-emit fails partway. **Gate (criterion 4):** a RED test injects a mid-write failure into a re-emit and asserts the artifact is EITHER the prior-good one OR the new complete one — never a partial-state file. The maintained module's own write-to-temp-then-rename (mirroring `store._write_atomic`) is the mitigation; a test that injects the failure and finds a truncated/half-written artifact FAILS. Must be able to turn red when the write is non-atomic.
- **Risk R2 — widened local-PII surface + the name scan-scope hole (ADR-0025 Consequence-Negative-2 + Negative-3).** The maintained artifact is the long-lived gitignored file ADR-0021 re-inserts real PII onto; a misrouted/force-added re-emit leaks PII to public history. **Gate (criterion 5, the crown jewel, threshold 0):** a RED test crafts a maintained re-emit carrying re-inserted real PII (a synthetic identity token — 0 real operator PII in the test tree), stages/commits and stages/pushes it, and asserts `block-pii-commit.sh` AND `pre-push-pii-scan.sh` both DENY — 0 real-PII values reach any tracked/committed file. This exercises the T0-SCANSCOPE coverage; a leak past either hook is release-blocking (ADR-0005 falsification). Must turn red if the scope hole is open.
- **Risk R3 — format-then-fill order broken (ADR-0021 Rationale, via ADR-0025-T1 crit 6).** A fill-then-render order would clobber the re-inserted name. **Gate (criterion 6):** a RED test asserts the maintained render (`render.emit`) runs BEFORE the deterministic name-fill (`reinsert_out`), `reinsert_out` is the FINAL pass over the produced HTML, and the re-inserted name SURVIVES into the emitted artifact unmodified — 0 renders clobber a re-inserted name. A pipeline that fills first then re-renders (dropping the name) FAILS.
- **Risk R4 — store read/write keying defects (store-surface mandate, bead `pka`, via ADR-0025-T1 crit 7).** A cross-stream collision returns a fabricated value; a same-timepoint dedupe-drop silently loses a tracking entry AT THE STORE (the S41 safety-surface escape). **Gate (criterion 7):** the four required adversarial categories over the `track.resolve_plan_progress` read + `track.record_tracking` write paths — cross-stream collision, same-timepoint dedupe (SPLIT BY LAYER: STORE-level both distinct snapshots persist; FOLD/READ-level `resolve_tracking` is latest-appended-wins so the fold renders the latest snapshot, identical re-entry idempotent), dedupe-key boundary, mutation observed RED. Category 4 (mutation) MUST be run RED (e.g. dedupe key widened to include `value`, or a stream prefix removed) and observed failing, then reverted; a battery that stays green under the mutation is tautological and FAILS the `pka` checklist.
- **Risk R5 — single-file portability budget broken (Constraint ADR-0004, via ADR-0025-T1 crit 2).** A re-emit that pulls an external asset or exceeds <500KB breaks the offline/portable artifact. **Gate (criterion 2):** a RED test asserts each emitted/re-emitted artifact is one self-contained offline file with 0 external asset requests (via `render.emit`'s external-reference raise) and size < 500000 bytes.

These five gates (criteria 4, 5, 6, 7, 2) plus criteria 1 and 3 are first-class RED targets below — each is falsifiable.

## Interface Contracts

It **CONSUMES** these already-published contracts (MUST NOT change any signature — changes require Architect review):

- **`render.emit(template, store_read, *, _out_dir=None) -> Path`** (ADR-0004-T1): the re-emit primitive; inline-only / 0-external-ref / <500KB budget. Driven, never edited.
- **`reinsert_out(html, target_path) -> str`** (ADR-0021-T1): the deterministic OUT pass; returns the (name-bearing or initials-only) HTML string, writes nothing, fail-closed to initials-only on a non-gitignored target. - **`track.resolve_plan_progress(domain, on_date, root)` + `track.record_tracking(domain, tracking, on_date, root)`** (ADR-0010 store surface): the plan-vs-actual read + the MEASURE-leg write the fold drives. - **The gitignored `vault/artifacts/generated/` output target** (`.gitignore:6`): the ONLY destination for the PII-bearing maintained artifact; the SEC-01 caller-precondition is the REALPATH-CONTAINMENT check (`os.path.realpath(target)` under `os.path.realpath(vault/artifacts/generated/)`, fail-closed on any symlink-divergent / `..`-traversal / non-contained escape) — `git check-ignore` alone is symlink-bypassable and is NOT the containment guard.
