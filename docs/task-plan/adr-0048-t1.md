- **Risk (D4 — shared confidential-client `client_secret` extractable + global-revoke; ADR-0048 Consequence-Negative "D4 shared confidential-client secret extractable/global-revoke"):** a shared vendor secret persisted to a TRACKED path is a committed-credential exposure that global-revokes every tester's connection.
  - Gate condition — **out-of-band ONLY (AC-1 + AC-4):** `test_loads_from_out_of_band_env_path` — a shared vendor cred set + shared key load from an env-var-named path OUTSIDE the repo tree; `test_unset_env_var_empty_config` — env var UNSET → an EMPTY config (0 vendor creds, no shared key — assert emptiness, NOT just no-exception — QA-F5), NO exception (connect degrades to per-vendor manual/skip). `test_in_repo_config_path_rejected` — a config path resolving INSIDE the repo working tree RAISES; the config can ONLY be out-of-band. **CASE-FOLD reject (SEC-1, macOS/APFS bypass — the operator's OS):** `Path.resolve().is_relative_to(repo_root)` is a LEXICAL, case-SENSITIVE compare, and `Path.resolve()` does NOT case-fold on a case-insensitive filesystem — so an in-tree path with a case-variant segment (`A-PLUS-MAXING/scripts/serve/secret.conf`) is physically reachable but NOT rejected → the in-tree config loads (defeats the ADR-0005 out-of-band-only control; the AC-3 scan + PII hooks only fire once the file is git-ADDED, so an in-tree-but-untracked file — exactly what AC-4 prevents — slips). The reject MUST case-normalize BOTH operands (`os.path.normcase` on the resolved config path AND `repo_root`, or `os.path.commonpath([...]) == normcase(repo_root)`). RED-capable: a loader reading a tracked in-repo path (same-case) without raising → RED; **a case-VARIANT in-tree path that loads un-rejected → RED (the SEC-1 bypass test)**; an unset-var path that raises instead of returning empty → RED; a populated config on an unset var → RED (emptiness).
  - Gate condition — **tracked-secret-scan == 0 (AC-3; ADR-0005 — QA-F1/SEC-3):** `test_no_tracked_secret` — `git ls-files` piped to a secret-VALUE-SHAPE grep, NOT the bare identifier.
