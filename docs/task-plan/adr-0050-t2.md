## Interface Contracts

`_author_system_prompt(domain)` keeps its signature (`domain: str` → `str`) and its single production call site (`_ClaudeNoTrainBackend.author` @769) unchanged — this task rewrites only the returned string and adds two internal helpers (`_CONTRACTS_PATH`, `_contract_section`) plus one map (`_AUTHOR_CONTRACT_SECTION`), all module-private. It does not create or modify a shared public interface.

**`author`'s error contract WIDENS (AMEND-3, Arch-F1) — state the breaks-if, add no guard.** The new un-memoized `_CONTRACTS_PATH` read runs inside `_author_system_prompt`, called at `client.py:769` — BEFORE the retry/except loop. So if the contract file is absent or renamed at runtime, the `FileNotFoundError` escapes `author` UNCONVERTED, bypassing the `raise ModelCallError(...) from None` boundary (@791) that otherwise guarantees `author` raises ONLY `ModelCallError`. This widens `author`'s error contract: a caller catching only `ModelCallError` will not catch this. **Breaks-if:** the contract file must be present at runtime — it ships in the repo (`design/specialist-plan-contracts.md`), so this is fail-loud-on-broken-deploy, the intended posture. This is NOT grounds for a defensive `try/except` around the read (unmotivated per CLAUDE.md — the file always ships; a guard would convert a loud deploy break into a silent degraded prompt). State the breaks-if; do not add the guard.

One real (non-phantom) downstream behavioral contract is worth pinning, because the dependency map has the edge `ADR-0050-T2 --> ADR-0051-T1` (spec Dependency Map; ADR-0051 Negative-4): the prompt now carries a raw-genotype-interpretation directive (AC-2). ADR-0051-T1 carries the operator's raw `GENE rsID = (C;C)` panel to the author payload and RELIES on this directive to make those calls interpretable — so ADR-0051-T1 MUST NOT be built assuming the prompt lacks the genotype-interpretation directive. This is a semantic contract (directive present), not a signature change; it is verified by AC-2, not by an interface signature.

**Cross-task genotype-SHAPE note — carries to the Wave-2 0051-T1 build (AMEND-5, Arch-F2; recipe note only, no T2 change).** T2's AC-2 directive teaches the illustrative `GENE rsID = (C;C)` (equals-infix) shape, but ADR-0051-T1 (Wave-2) delivers the genotype into the author payload as a JSON dict entry — the user-message `json.dumps(summary)` (@773) renders it as `"<GENE> <rsID>": "(X;Y)"` (colon key/value join), NOT `= (X;Y)`. The `(X;Y)` allele-tuple itself matches; only the key↔value JOIN differs. This is the ADR-0051 Negative-4 "carried but unused" seam: the `= ` form is illustrative of the SAME JSON key/value call the specialist must interpret. The reconciliation (aligning the directive's illustrative shape with the actual `json.dumps` rendering, or confirming the model reads both) lands in the 0051-T1 build, not here — flagged so the 0051-T1 author does not treat the shape mismatch as a T2 defect.
