# Recipe: Genetics Genotype-Fact Extraction Mapping — Capture-All, Fact-Not-Interpretation, PROMPT-ONLY (No Schema Change; Fixture-Backend Non-Tautology; Mock-Tested; 0 Live Spend)

A Wave-1 entry task (parallel with T1/T2; no inbound edge). It tunes ONE constant string — the no-train extract SYSTEM
instruction `_extract_system_prompt` ([client.py:282-300]) — so a genetics/SNP report's text maps to DURABLE GENOTYPE FACTS in
the existing Line-Field-Set store: `item` = the gene symbol + rsID (e.g. `"MTNR1B rs10830963"`), `timepoint` = the genome sample
date (e.g. `"2019-12-13"`), `source` = `"dna-report"`, `value` = the alleles (e.g. `"(C;G)"`). The prompt additionally instructs
the model to capture EVERY SNP finding (not a "Noteworthy" subset) and to store the durable genotype FACT, NOT the report's dated
INTERPRETATION (the trait/risk narrative). This is the honest-data move ADR-0031 names: the allele call is the durable fact
re-derivable against current evidence at plan time; the report's interpretation is stale and is not stored as truth.

It is a **PROMPT-ONLY** change. `_extract_output_schema` ([client.py:334-360]) already constrains every reading to the four
`keying.LINE_FIELDS` (`item`, `timepoint`, `source`, `value`), each `{"type": "string"}` — the genotype fact maps onto those four
fields EXACTLY, so **no schema change is needed and none is made** (no second data model — ADR-0031 non-goal #3; the genetics
readings land via the UNCHANGED `confirm.land_confirmed`/`store.append` sink). `_extract_content_block` (the egress surface),
`_extract_output_schema`, `_parse_extract_readings`, `ModelClient.extract_readings`, `_ClaudeNoTrainBackend.extract_readings`,
`deidentify`, `converse`, `author`, and every other `client.py` body are **byte-unchanged** (EXTEND-NOT-REBUILD; scoped change).
The prompt is a CONSTANT system string — no file content is interpolated into it (the file is carried natively as the user-turn
content block) — so the crown-jewel egress lane is untouched: T3 adds no outbound surface and changes 0 bytes of the egress path.

The build is MOCK/FIXTURE-tested at the ADR-0015 seam at 0 live spend (`_FakeAnthropic`/`_patch_backend_client`,
[test_client.py:418,473]) — no live API, no key, no network. The operator-present LIVE run (real key + the real 42-page
genetics/SNP report + real spend — where the model's ACTUAL adherence to the genotype-fact prompt is observed) is ADR-0031 OQ-1,
the operator-gated checkpoint AFTER the build, in no wave.
