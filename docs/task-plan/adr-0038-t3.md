## Risk Pre-Check

The spec task block for ADR-0038-T3 carries risk mitigations; each maps to a binary AC and must be covered by a real (non-`assert True`) test in the RED phase.

- **ADR-0038 Consequences-Negative-3 / RT-09 (loop-densified history):** the ADR-0036 loop day-keys a NEW dated `plan::<domain>` set on every trigger, so multiple dated plans can fall in one week/month window. Gate: a test seeds two same-window dated plans and asserts the range query selects the latest-in-window as "the block" (AC-2). A test that seeds only one plan per window does not exercise the densified case and FAILS this gate.
- **ADR-0038 Validation "no-new-stream probe" + single-progress-site:** the composition and classifier must write no new `::`-prefixed store stream and derive progress through exactly one site. Gate: a test scans the store after the horizon read for `plan-arc::`/`horizon::`/`periodization::` (0 hits) AND asserts the classifier's actual-rate read reaches the derived goal percent only via `resolve_goal` (no second `_percent` caller feeding a horizon reading) — AC-1 + AC-5.
- **ADR-0038 Validation "today-by-date-equality probe":** the today slot must resolve by exact date equality, never nearest-date. Gate: a test seeds a plan dated yesterday and a plan dated the render date, asserts the render-date plan wins; and with NO render-date plan asserts `NO_PLAN_TODAY`, never the yesterday plan (AC-3).
- **ADR-0036 Validation "machine-comparable expectation vs actual":** the classifier must be a deterministic pure comparison, no model call. Gate: a test drives fixed `(expectation, actual)` pairs through the classifier and asserts each maps to a fixed `behind`/`on-track`/`ahead` verdict with the presentation/model layer never invoked (AC-4).
