# Recipe: Question Strategy — De-Identified Store-Grounded Gap-Set (Hybrid, CONCERN-1)

This task produces CODE: the `plan_next_turn(summary, covered_domains, declined_domains)`
function in `scripts/serve/chat.py` — the STRATEGY half of the conversational-intake hybrid
(code owns the de-identified gap-set + `domain_done`/`intake_complete`; the model owns phrasing
within the gap set, in `ADR-0016-T1`). It reads operator-capture state ONLY through the
de-identified `router.summarize(store_read)` surface ([router.py:352](../../scripts/plan/router.py#L352)
[VERIFIED]) — never the raw transcript, never the gitignored scaffold — and returns a
`TurnIntent{target_domain, missing_fields, domain_done, intake_complete}` carrying only token
NAMES, domain names, and booleans (0 raw operator string). `domain_done` is STORE-grounded +
explicit-decline (never turn-count / model say-so — the PF-S87-01 anti-gap), and a chat-covered
domain whose ADR-0019 token is NOT yet minted reports "captured-for-record, not-planned", never
`domain_done` vacuously (Design CONCERN-1). It PUBLISHES the strategy consumed by `ADR-0016-T1`'s
per-turn dispatch. No model call lives in the strategy itself — it lives in `chat.py` alongside
the client-driven dispatch `ADR-0016-T1` adds. The TDD Steps follow the standard
RED/GREEN/REFACTOR/REGRESSION cycle.

## Risk Pre-Check

Active. Each gate maps to a concrete `pytest` test or `rg` assertion. A placeholder (`assert True`) fails each gate.

- **Design §1.2 (a silently-dropped decline leaves a domain re-asked forever; a turn-count "done" leaves a domain silently un-captured — the PF-S87-01 anti-gap).** Mitigation: criteria 2, 5. **Gate (store-grounded done, falsifiable):** a RED test asserts a domain with a MISSING `SUMMARY_FIELD_SET` token is NOT `domain_done` even after N turns, and a DECLINED domain IS done; a separate assertion proves `domain_done` does NOT rest on turn count or model say-so (pass a high turn count with a missing token → still not done). **Falsifiable RED:** the assertion turns RED if `domain_done` becomes true on turn-count alone. **Negative-control:** temporarily make `domain_done` true at a turn threshold regardless of the store, confirm the "not-done-with-missing-token" assertion FAILS, then revert to the store-grounded form and confirm it passes.
- **CONCERN-1 / PF-S87-01 (rich capture that never feeds the plan — a chat-covered domain with no minted token must not vacuously report done).** Mitigation: criterion 3. **Gate (record-only, not done, falsifiable):** a RED test with a chat-covered domain ABSENT from `SUMMARY_FIELD_SET` (empty `missing_fields` for a not-planner-feeding domain) asserts it reports the "captured-for-record, not-planned" state and is NEVER `domain_done`. **Negative-control:** temporarily collapse the record-only state into `domain_done`, confirm the CONCERN-1 assertion FAILS, then revert and confirm it reports record-only.
- **ADR-0016 raw-egress bound (the control surface must be de-identified — `TurnIntent` carries 0 raw operator string).** Mitigation: criteria 1, 4. **Gate (de-identified-only, falsifiable):** a RED test asserts `rg` finds 0 raw-transcript / scaffold read in `plan_next_turn` (it reads ONLY `router.summarize(store_read)`), AND a test asserts the returned `TurnIntent`'s values are token NAMES / domain names / booleans only (`missing_fields ⊆ SUMMARY_FIELD_SET`, 0 raw turn text).

## Interface Contracts

This task PUBLISHES the question strategy consumed by `ADR-0016-T1`'s per-turn dispatch, so the contract is load-bearing.

- **Function:** `plan_next_turn(summary, covered_domains, declined_domains) -> TurnIntent{target_domain, missing_fields, domain_done, intake_complete}` in `scripts/serve/chat.py` — **NAMED CONTRACT (frozen at this task):** computes the next-turn gap-set from the de-identified `router.summarize` mapping + the covered/declined domains. **Invariants (load-bearing):** (a) it reads ONLY the de-identified `summarize(store_read)` surface — 0 raw transcript / scaffold read (AC-1); (b) `domain_done` is STORE-grounded + explicit-decline, never turn-count / model say-so (AC-2, the PF-S87-01 anti-gap); (c) a chat-covered domain with no `SUMMARY_FIELD_SET` token reports record-only, never `domain_done` vacuously (AC-3, CONCERN-1); (d) `TurnIntent` carries 0 raw operator string — token/domain names + booleans only, `missing_fields ⊆ SUMMARY_FIELD_SET` (AC-4). **Dependent:** `ADR-0016-T1`'s per-turn dispatch drives `plan_next_turn` → `client.converse` → `extract_facts` → `persist_capture` → receipt. **Breaks if:** the strategy reads the raw transcript / scaffold (crosses the crown-jewel PII boundary), or `domain_done` rests on turn count / model say-so (re-opens the PF-S87-01 gap).
