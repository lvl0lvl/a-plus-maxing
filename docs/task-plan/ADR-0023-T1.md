## Risk Pre-Check

The spec task block carries a non-empty Risk Mitigations field. Two gates apply.

- **Risk: Rubber-stamping** (ADR-0023 Negative; judge-discipline §2 — "LLM judges default to agreeable high scores").
  - Gate condition: a test must exist that SEEDS a quality defect into an assembled plan and asserts the judge does NOT return ACCEPT (it returns a quality-defect verdict / triggers the loop). A test that only feeds a clean plan and asserts ACCEPT does NOT discharge this risk.
  - The RED phase MUST include the seeded-quality-defect test (Cycle 2, AC-3). A placeholder (`assert True`) or a clean-only test fails this gate.
- **Risk: Producer judging its own output** (judge-discipline §1 — independence is the judge's only source of trust).
  - Gate condition: a test must assert the judge's input EXCLUDES the specialists' self-assessments and the orchestrator's notes (AC-2). A judge fed the producer's self-scores cannot be independent; the test inspects the judge dispatch payload and asserts those fields are absent.
  - The RED phase MUST include the producer-independence test (Cycle 1, AC-2).

The bounded-revise cap N=3 is NOT a risk this task gates — it belongs to ADR-0022-T2 (the loop owner), per the SHARED OQ-2 single-loop resolution. This task's verdict FEEDS that loop; it does not bound it.

## Interface Contracts

This task defines one contract consumed by ADR-0022-T2 (the revise-loop owner, Wave 4) and read alongside ADR-0024-T1's parallel safety gate:

- **`quality_judge(assembled_plan, judge_client) -> verdict`** — a producer-independent callable shaped to be injected as the orchestrator's `gate_dispatch=` QUALITY gate. It scores the assembled-plan dict (`{"sections": [...]}`, the `assemble`/`run_generation` output) against `vault/design/plan-quality-rubric.md` via the injected judge client (producer-independent: assembled plan + rubric only) and returns a verdict object exposing ACCEPT vs a quality-defect (REVISE) disposition the revise loop reads WITHOUT re-adjudication. The SE fixes the exact signature/return-shape at GREEN; once set, ADR-0022-T2 MUST NOT change it without Architect review.

The **`gate_dispatch=` seam invocation point** (calling the gate over the assembled plan post-`run_generation`, pre-surface, in `run_orchestrated`'s body) is ADR-0022-T2's, NOT this task's — this task builds the spy-injectable callable shaped to BE that gate, mirroring ADR-0024-T1. ADR-0024-T1 builds the SAFETY callable for the same seam; ADR-0022-T2 composes both verdicts into the single bounded loop.

The QUALITY judge (this task) and the SAFETY review (ADR-0024-T1) share the `gate_dispatch` seam but are DISTINCT gates: quality scores followability/coherence/consistency/completeness; safety screens clinical risk over the composed plan. Neither re-implements the other; the loop (ADR-0022-T2) reads both verdicts.
