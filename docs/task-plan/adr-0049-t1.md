# ADR-0049-T1 — Bounded metered dispatch factory into the injected seam + the D2 wire-scan

## Goal

Build the metered specialist-author dispatch factory `scripts/runner/metered_dispatch.py`
— the metered-lane analog of `scripts/runner/subscription_dispatch.py:build_dispatch` — and
wire it as the production server's `loop_dispatch` at operator-entry start, so in-app plan
generation dispatches specialists through the `run_orchestrated`→`plan_driver.drive` seam
authenticating on the shared `a-plus-maxing-api-key` metered lane (ADR-0048 D5: testers
"touch nothing"), with the ADR-0048-T1 shared-key provisioning bridge invoked at start so
`key_source.resolve` returns the shared key on the no-BYO default.

The load-bearing deliverable is the **D2 crown-jewel wire-scan**: an executed, mutation-gated
egress test proving the metered lane sends the model API — **captured at the true SDK boundary
(`_ClaudeNoTrainBackend`'s `messages.create`), not the seam-inbound args** — only the
de-identified summary (⊆ `SUMMARY_FIELD_SET`), **0** raw operator PII, **0** store-content
bytes, with the adapter performing **0** store reads (enforced structurally AND spy-gated),
the placement guarantee that the `deid_in` boundary halts to **0** metered dispatches on the
de-id sentinel, and the lane-swap invariance that the de-id egress guarantee (0 raw-PII, 0
store-content) holds identically across a metered↔subscription swap.

**Scope of the guarantee (precise — Phase-4 Sec LOW-1 / Arch F3).** This scan proves the
**adapter-forwarding + backend-serialization egress half**: given the de-identified summary the
`deid_in` boundary produced, the metered lane crosses only that summary to the model API. The
**de-identification half** (that `deid_in`/`AggregatingDeidClient` actually strips raw PII to a
`SUMMARY_FIELD_SET` summary) is guaranteed upstream at the ADR-0020/0027 de-id boundary, NOT
re-proven here. The scan is **specialist-dispatch-scoped** (the ADR-0049-T1 `loop_dispatch`
surface); the judge/lens producer built from the SAME metered `dispatch`
(`plan_loop.py:295 compose_gate_dispatch(_JudgeClient(dispatch), dispatch)`) egresses the same
adapter, so it INHERITS the adapter's 0-raw-PII/normalize guarantee — but its distinct payload
(the assembled plan, itself composed only from de-id authors) is the ADR-0028 gate-dispatch
surface, out of this task's scope (noted, not silently omitted).

## Design (what the SE builds — no literal code here; this is the contract)

### `scripts/runner/metered_dispatch.py` (CREATE)

A faithful mirror of `subscription_dispatch.build_dispatch`, over the metered lane:

- **`build_dispatch(client)`** → returns `dispatch(name, prompt, context) -> author envelope`.
  The returned closure calls `normalize_author_output(client.author(name, context))`. `client` is
  a `ModelClient` (the metered-lane analog of subscription's injected `session`) whose
  `.author(domain, summary)` authenticates via the shared `a-plus-maxing-api-key` metered lane
  (`key_source.resolve` through `_ClaudeNoTrainBackend`).
- **Gate-blindness "breaks if" (Phase-4 Arch F1 — document the bounded asymmetry).** The
  pre-built role-inlined `prompt` (the subscription lane's subprocess input) is NOT resent on the
  metered lane — `ModelClient.author` builds its own metered-API prompt from `(domain, summary)`,
  so ONLY the de-id `context` (summary) is the operator-state that crosses. The discarded `prompt`
  carries THREE components (`_dispatch_prompt`, `plan_orchestrator.py:101-124`): the role profile,
  the summary, AND the `## Active gates` block. The metered author is therefore **gate-blind**.
  This is SOUND today — gates are ALSO forwarded independently to the deterministic composer
  (`run_generation`, `plan_orchestrator.py:157-159`), so gate enforcement is downstream +
  author-independent; and the live loop path passes empty `gates=` (`plan_loop.py:296-298`), so
  the divergence is dormant. **Breaks if** a future task populates `run_orchestrated`'s `gates=` on
  the loop path: the subscription author would see them, the metered author silently would not —
  an author-visible-safety-context divergence. Record this "breaks if" in the module docstring.
- **Structural 0-store-read guarantee (Phase-4 Sec MEDIUM-2 / QA MUST-FIX-1).** The module imports
  NO `scripts.store` symbol (mirror subscription_dispatch's import set: `normalize_author_output`
  only, plus whatever the client type needs — NOT the store). The adapter closure captures only
  `client` — no store handle, no `raw_intake` handle. This is the primary no-store guarantee; the
  AC-5 spy + mutant is the backstop proving it non-tautological.
- `normalize_author_output` is idempotent here (`ModelClient.author` already normalizes) — applied
  for mirror parity + to cover a non-`ModelClient` recording client in tests. Module import fires 0
  side effects (0 dispatch, 0 key resolve, 0 model call). `subscription_dispatch.build_dispatch`
  is UNTOUCHED — stays built + importable (AC-1: the retained North-Star adapter).

### `scripts/serve/__main__.py` (MODIFY `main()`)

At operator-entry server start, before building the server:

1. **Invoke the D5 bridge:** `alpha_config.provision_shared_key(alpha_config.load_alpha_config())`
   — if no BYO key resolves, the shared key is exported to `os.environ[ENV_VAR]` and the metered
   lane's `key_source.resolve` returns it on the default (0 `KeyUnavailableError`). A BYO key makes
   the bridge no-op (0 clobber — HIST01 `e0wp`). **No `print`/`log`/`repr` of the config or the key**
   (AC-8; bead `d1yz` — the dataclass repr leaks the secret).
2. **Build the metered loop seams:** construct the metered `loop_dispatch` via
   `metered_dispatch.build_dispatch(<a ModelClient>)` and the `loop_deid_client` via
   `AggregatingDeidClient(<a ModelClient>)` (mirror `cadence_runner.py:118`). Both `ModelClient`
   constructions are 0-spend (lazy backend).
3. **Pass BOTH to `build`:** `build(port, client=..., loop_dispatch=<metered>, loop_deid_client=<deid>, **roots)`.
   BOTH must be non-None (the `or`-guard, `server.py:893`).
4. Keep `main()`'s injectable seams (`build=`, `client_factory=`) so the wiring is testable without
   a socket or a live call (AC-2/AC-8 drive `main()` with a spy `build`). Replace the honest-degraded
