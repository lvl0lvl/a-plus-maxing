# ADR-0049-T1 — Bounded metered dispatch factory into the injected seam + the D2 wire-scan

## Goal

Build the metered specialist-author dispatch factory `scripts/runner/metered_dispatch.py`
— the metered-lane analog of `scripts/runner/subscription_dispatch.py:build_dispatch` — and
wire it as the production server's `loop_dispatch` at operator-entry start, so in-app plan
generation dispatches specialists through the `run_orchestrated`→`plan_driver.drive` seam
authenticating on the shared `a-plus-maxing-api-key` metered lane (ADR-0048 D5: testers
"touch nothing"), with the ADR-0048-T1 shared-key provisioning bridge invoked at start so
`key_source.resolve` returns the shared key on the no-BYO default.

The load-bearing deliverable is the **D2 crown-jewel wire-scan**: an executed, mutation-gated
egress test proving the metered lane sends the model API **only** the de-identified summary
(⊆ `SUMMARY_FIELD_SET`), **0** raw operator PII, **0** store-content bytes, and performs **0**
store reads — with the placement guarantee that the `deid_in` boundary halts to **0** metered
dispatches on the de-id sentinel, and the lane-swap invariance that a metered↔subscription
swap changes **0** bytes of the outbound operator-state payload. This is the first Wave-3
crown-jewel egress surface; the scan is the mechanical guarantee the metered lane cannot leak.

## Design (what the SE builds — no literal code here; this is the contract)

### `scripts/runner/metered_dispatch.py` (CREATE)

A faithful mirror of `subscription_dispatch.build_dispatch`, over the metered lane:

- **`build_dispatch(client)`** → returns `dispatch(name, prompt, context) -> author envelope`.
  The returned closure calls `normalize_author_output(client.author(name, context))` and returns
  it. `client` is a `ModelClient` (the metered-lane analog of subscription's injected `session`)
  whose `.author(domain, summary)` authenticates via the shared `a-plus-maxing-api-key` metered
  lane (`key_source.resolve` through `_ClaudeNoTrainBackend`). The pre-built role-inlined `prompt`
  (the subscription lane's subprocess input) is NOT resent on the metered lane — `ModelClient.author`
  builds its own metered-API prompt from the de-identified `(domain, summary)`, so ONLY the de-id
  `context` (summary) is the operator-state that crosses. `normalize_author_output` is idempotent
  here (`ModelClient.author` already normalizes at its boundary, bead ec4e) — applied for mirror
  parity + to cover a non-`ModelClient` injected client in tests.
- The module reads no store, de-identifies nothing, re-hosts no loop logic (the de-id-IN happens
  INSIDE `run_orchestrated` upstream of this seam — mirror the subscription_dispatch docstring's
  exact contract). Module import performs 0 side effects (0 dispatch, 0 key resolve, 0 model call).
- `subscription_dispatch.build_dispatch` is UNTOUCHED — it stays built + importable (AC-1: the
  retained North-Star adapter).

### `scripts/serve/__main__.py` (MODIFY `main()`)

At operator-entry server start, before/at building the server:

1. **Invoke the D5 bridge:** `alpha_config.provision_shared_key(alpha_config.load_alpha_config())`
   — so if no BYO key resolves, the shared key is exported to `os.environ[ENV_VAR]` and the metered
   lane's `key_source.resolve` returns it on the default (0 `KeyUnavailableError`). A BYO key makes
   the bridge no-op (0 clobber). No model call; no key value logged.
2. **Build the metered loop seams:** construct the metered `loop_dispatch` via
   `metered_dispatch.build_dispatch(<a ModelClient>)` and the `loop_deid_client` via
   `AggregatingDeidClient(<a ModelClient>)` (the de-id IN client — mirror `cadence_runner.py:118`).
   Both `ModelClient` constructions are 0-spend (lazy backend; spend is metered only at
   `.author`/`.deidentify` call time).
3. **Pass BOTH to `build`:** `build(port, client=..., loop_dispatch=<metered>, loop_deid_client=<deid>, **roots)`.
   The guard downstream is `or` (BOTH needed — `test_plan_loop_route_honest_when_half_wired`), so
   both must be non-None for the loop to be live.
4. Keep `main()`'s injectable seams (`build=`, `client_factory=`) so the wiring is testable
   without binding a socket or making a live call. Add a `bridge=` / metered-builder injection
   point ONLY if needed for the AC-2 test (prefer reusing `build`/`client_factory` + monkeypatching
   `provision_shared_key`). The `python -m scripts.serve` honest-degraded comment block (`:69-75`)
   is REPLACED by a comment describing the metered wiring (the standalone server is now loop-live
   on the metered lane, not seamless).

2. **Production wiring + bridge closes the default (AC-2).** In `test_loop_dispatch_wiring.py`:
   drive `__main__.main()` with an injected spy `build` (captures kwargs) + a `client_factory`
   stub + `provision_shared_key`/`load_alpha_config` monkeypatched over a fixture config carrying
   a synthetic shared key + NO BYO key (monkeypatch `ENV_VAR` unset + an empty keychain runner).
   Assert: (a) `build` received a non-None `loop_dispatch` AND a non-None `loop_deid_client`;
   (b) after `main()` runs the bridge, `key_source.resolve()` returns the shared key (0
   `KeyUnavailableError`) — the D5 default resolves. **Load-bearing mutation:** monkeypatch the
   bridge call OUT of `main()` (or make `provision_shared_key` a no-op) → `key_source.resolve()`
   raises `KeyUnavailableError` (RED). Separately (in `test_metered_dispatch.py`), an end-to-end
   `run_orchestrated` over the metered `loop_dispatch` (mocked recording client) + a clean-summary
   `deid_client` completes a plan with **0** `subscription_dispatch`/`oauth_pull` reads (assert via
   a spy on `oauth_pull._read_oauth_credential` / no subscription session constructed).

3. **D2 wire-scan (i) Placement (AC-3).** With a sentinel-returning `deid_client` fixture
   (`deidentify(raw_intake) -> {"deidentified": False}`), a `run_orchestrated` (or `regenerate`)
   run over the metered `loop_dispatch` (a spy client counting `.author` calls) invokes the metered
   client **EXACTLY 0 times** and never receives `raw_intake` — the `deid_in` gate halts to 0
   dispatches at `plan_orchestrator.py:227` before any specialist dispatch. Assert
   `spy.author_call_count == 0` AND the run returns the honest-no-plan `{"deidentified": False, ...}`
   shape with `dispatch_count == 0`. Falsifier: a fixture returning a clean summary → the spy IS
   called (proves the 0-count is the sentinel halt, not a dead seam).

4. **D2 wire-scan (ii) Outbound capture (AC-4).** With a clean-summary `deid_client` fixture whose
   output `set(summary) ⊆ SUMMARY_FIELD_SET`, and a synthetic legal-name + store-content sentinel
   seeded into `raw_intake` (the de-id STRIPS them — they are absent from the summary), run the
   metered dispatch through the seam with a **recording backend** injected into the metered
   `ModelClient` (the backend records the ACTUAL outbound `author(domain, summary)` payload — the
   bytes it would serialize to the model API, not the seam-inbound args). Assert the recorded
   outbound: (a) `set(recorded_summary_keys) ⊆ SUMMARY_FIELD_SET` (0 field outside the allowlist);
   (b) the synthetic legal name (raw-PII) appears **0** times in the serialized outbound; (c) the
   store-content sentinel appears **0** times; (d) the adapter performed **0** store reads (a
   `store_read` spy passed nowhere near the adapter is never called — the adapter has no store
   handle). Falsifier: seed a summary field OUTSIDE `SUMMARY_FIELD_SET` and assert the ⊆ check
   REDs (proves the assertion binds to the real allowlist, not a tautology).

5. **D2 wire-scan (iii) lane-swap invariance + (iv) mutation gate (AC-5).**
   - **Lane-swap invariance:** capture the outbound operator-state payload once through the metered
     adapter and once through `subscription_dispatch.build_dispatch` (a recording session), over the
     SAME clean de-id `context`. Assert the operator-state that crosses (the `context`/summary
     forwarded to each lane's author) is **byte-identical** across the swap — 0 bytes change (both
     forward the de-id summary; the crown-jewel egress invariant is lane-insensitive).
   - **Mutation gate (self-invalidation, the D2 gold standard the spec references at line 204):**
     (a) a metered-adapter STUB that appends a raw field to its outbound call (e.g. injects the
     seeded raw legal name into the forwarded summary) MUST flip the AC-4 ⊆-`SUMMARY_FIELD_SET` /
     0-raw-PII assertion RED; (b) a metered-adapter STUB that opens a store read MUST flip the
     AC-4 0-store-read assertion RED. The test asserts BOTH mutants go RED — **the test is invalid,
     and itself fails, if either mutation does not RED the scan** (encode this as an explicit
     `pytest.raises(AssertionError)` around the scan run over each mutant, so a scan that cannot go
     RED fails the meta-assertion).
