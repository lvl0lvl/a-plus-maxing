# Recipe: Single Bounded Revise Loop (Both Gates, Safety-Blocking, N=3 Halt)

The KEYSTONE. This task finally INVOKES the `gate_dispatch=` seam that has been HELD (resolved
+ charge-wrapped, never called) in `run_orchestrated`'s body since ADR-0022-T1, and composes
both Wave-3 gates (`quality_judge` + `safety_review`) into ONE bounded revise loop: after the
inner engine assembles the plan, run BOTH gates over the `run_generation` result → on a quality
REVISE (with safety passing) re-DISPATCH the REVISE-targeted domain(s) through the orchestrator's
`dispatch` seam (the same seam that built the initial `authors`, NOT the energy-bounce `reauthor`
hook — MF-1) + re-run the inner engine + re-run BOTH gates → bounded cap N=3 → on non-convergence
HALT to honest no-plan. The safety disposition is FAIL-CLOSED: `safety_passed is True` is the ONLY
surface path; a `False` / absent / ambiguous / un-composed safety verdict is TERMINAL `SAFETY_BLOCKED`
(never overridden, never looped past — the autonomous posture's secure default, HIGH-1).
INV-CRITICAL-NON-OVERRIDABLE: a seeded CRITICAL / H1-H2 inner hold surfaces 0 plans via ANY revise
pass — the loop must never launder the inner gate's non-overridable disposition into a surfaced plan.

This task WIRES the existing pieces; it re-authors nothing. The inner engine
(`orchestrate` / `pipeline` / `assemble` / `generate_plan` / `adjudicate` / `router` / `adjust` /
`track`) and the two gate callables (`quality_judge.quality_judge`, `safety_review.review_plan`)
stay BYTE-UNCHANGED (numstat = 0). `scripts/plan/plan_orchestrator.py` is the single wired file.

## Risk Pre-Check

This task carries risk mitigations from the spec (ADR-0022-T2 Risk Mitigations field). Before
proceeding to RED, verify a test exists (or the RED phase adds one) for EACH; a placeholder test
(`assert True`) fails this gate.

- **Risk R1 — unbounded loop (ADR-0023 Consequence-Negative-3 / ADR-0024 Consequence-Negative-2).**
  Gate: a non-converging quality miss HALTS at N=3 and records 0 plans past N. A test must seed a
  plan that never clears and assert `count of plans surfaced past N=3 revise passes == 0` (Cycle 3).
- **Risk R2 — multi-lens over-block / a standing safety block laundered to a surfaced plan
  (ADR-0024 Consequence-Negative-2/3, the load-bearing safety tier).** Gate: a seeded safety finding
  that re-fires every pass surfaces 0 plans — the loop never overrides a standing safety block, never
  loops past it (Cycle 4). A test must assert `count of plans surfaced past a standing safety block
  == 0`.
- **Risk R3 — INV-CRITICAL-NON-OVERRIDABLE laundered by the autonomous loop (ADR-0022 Falsification-2).**
  Gate: a seeded CRITICAL / H1-H2 inner hold WITH an override record surfaces 0 plans via ANY revise
  pass — the non-overridable tier is never laundered to a surfaced plan by the loop (Cycle 5). A test
  must assert `count of plans surfaced past a CRITICAL/H1-H2 inner hold == 0`, distinct from the
  standing-HIGH/MEDIUM-block probe (which a content-valid override CAN clear).

The gate conditions reference live tests, not subjective assessments. The crit-5 oracle is the
inner gate's existing non-overridable disposition (`adjudicate.is_non_overridable` →
`generate_plans` never releases the hold); this task's NEW obligation is that the revise loop does
not surface a plan for that domain by re-authoring/re-running around the standing hold.
