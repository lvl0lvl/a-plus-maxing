## Risk Pre-Check

**BLOCKING — this is a crown-jewel non-egress task.** Three risk mitigations from the spec's ADR-0036-T3 "Risk Mitigations" field gate this recipe; each requires a real, falsifiable test before GREEN. A placeholder (`assert True`) fails this gate.

- **Risk — Constraint ADR-0001/0034 finding-C de-id boundary (AC-4 + AC-5).** A raw operator token (legal name, raw medication name) reaching any specialist-lane dispatch payload on the loop path is the crown-jewel breach. Gate: a wire-scan test MUST seed a *synthetic* raw identifier + raw meds into the RAW intake, fire the loop through the free-text (care-chat) trigger, dump the actual specialist-lane dispatch payload, and assert 0 raw-PII hits — a NEGATIVE assertion over the dumped wire (not "the summary looks de-identified"). A second spy asserts the free-text trigger's dispatch payload carries only `WIRED_TOKENS`-derived tokens and 0 raw free-text strings. Both must be able to go RED if the boundary were removed.
- **Risk — ADR-0036 Validation "mutation control" (AC-2 + AC-3).** The re-gen must express DIFFERENT dispositions for a behind-goal trend vs an on-track/ahead trend, or the loop is not reading the re-derived trend. Gate: a falsifiable PAIR — a test asserting the two re-gen dispositions are NOT equal. A rule that produces the same disposition for both fails.
- **Risk — ADR-0036 Validation "held-domain persistence" (AC-6).** A domain held on the prior plan with no clearing signal on the new data must STAY held on the re-gen (clearance re-derived per re-gen, never inherited). Gate: a test asserting 0 silently un-held still-unsafe domains.

Before RED, confirm no existing test in `tests/serve/` already covers the loop-path wire-scan (the spec RGC-3 confirms it is new). If it existed and passed vacuously, that would be a tautological guard — RED must add the seeded-raw-PII negative assertion.
