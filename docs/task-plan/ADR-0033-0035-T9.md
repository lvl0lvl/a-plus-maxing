**The composed ADR-0033/0034/0035 falsification probes, each FAILING-CAPABLE (RED on the broken behavior; QA-F3
per-probe annotation):**
**(1) gate-bypass / hidden-until-complete** — AC-1/AC-2; REDs if a fresh/partial store serves ANY platform surface
(Dashboard / Plan / the unlocked Chat-with-Team platform / Generate Plan) instead of Create-Profile-only, or if the
required set incomplete / a safety screen unanswered UNLOCKS. **(2) non-tautological-headline / captured-signal** —
AC-1; REDs if a DIFFERENT filled profile yields the SAME de-id summary on all four serve-fillable tokens (a constant
summary — the feature is plumbed but the captured signal does not flow), or if the assertion is merely "a page was
served". **(3) crown-jewel PII boundary** — AC-3; REDs if a seeded raw-PII profile (legal name / full DOB / raw drug
name / PHQ-2 free-text answer / race string) produces ≥ 1 of those raw strings in the `dispatch` payload OR any model
request, OR if the de-associated EXACT AGE + current weight + trend do NOT reach the planner (the expected facts are
absent — an over-strip). **(4) editable-My-Info no-bypass (SEC-F1, behavioral)** — AC-3; REDs if a raw value driven
THROUGH the My-Info edit `/upload` re-submit path (a new raw drug name / a changed full DOB, NOT the initial intake)
crosses to the `dispatch` payload or any model request — the editable-My-Info no-bypass property proven BEHAVIORALLY, the
Security-reviewed companion to T7's W5 structural grep. **(5) safety-bypass** — AC-4; REDs if a positive
exercise-safety / PHQ-2 / apnea answer does NOT yield a `referral::<name>` flag, OR if a `safety-screen::*` / `referral::*`
item appears as a `SUMMARY_FIELD_SET` token / in the dispatched payload. **(6) serve-auto-classification + meds-curation
de-association** — AC-5; REDs if a raw med at intake produces ≥ 1 `rx-interaction-classes` store write from
`persist_capture` (the rejected ADR-0034 Alternative A), or if an unconfirmed curated class persists (the rejected
ADR-0035 Alternative C). **(7) extend-not-rebuild** — AC-6; REDs if `git diff --numstat <fork-point>` over the 7 frozen
`scripts/plan/*` engine files + `scripts/store/*.py` emits ANY row, or if `scripts/plan/router.py` is non-additive (the
`SUMMARY_FIELD_SET` tuple membership changed, the `dispatch` whitelist deleted, or deletions over the sanctioned cap).
**(8) 0-live-spend** — AC-7; REDs if the E2E makes a `key_source.resolve()`-gated live call, a live `converse`/curation
call, or opens a non-loopback socket.
