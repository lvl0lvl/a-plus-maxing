# Recipe: End-to-End DNA-Aware Plan — Fixture Genotype → Local Match → De-Identified Trait Token → Plan Signal + the Five ADR-0032 Falsification Probes (Non-Tautological; Mock/Fixture-Tested; 0 Live Spend)

This task produces a TEST FILE only — NO production file. It is the terminal Wave-3 integration gate and the headline
acceptance the whole ADR-0032 DNA-aware-planning slice exists to satisfy: a fixture `dna-report` genotype + a fixture
`vault/library/genetics/` page produces a plan signal that VISIBLY carries a current-science genetic-trait class —
through the LOCAL match → the de-identified `genetic-trait-classes` token → the existing `summarize`/`dispatch`/`author`
seam — with the raw rsID+allele genotype proven NEVER to cross to the no-train planner and the outbound variant query
proven de-associated. It creates the NEW `tests/genetics/test_dna_aware_plan_e2e.py` (`test ! -e` returns 0 today
[VERIFIED]) and composes the full DNA-aware chain into ONE end-to-end proof: a fixture `store_read` returning a
`dna-report` genotype (T2's read surface) → `scripts.genetics.match.match_genotypes` (T2) against a fixture
`vault/library/genetics/` page in the pinned T1↔T2 format → the de-identified `genetic-trait-classes` token via
`router.summarize` (T3) → `router.dispatch`'s whitelist → a mock `ModelClient.author(domain, summary)` (the ADR-0015
backend seam) that echoes the trait class into a recommendation → a plan signal whose recommendation TRACES to the
fixture finding's trait class. It is testable WITHOUT the live API — the plan-author model is a FIXTURE/MOCK injected at
the ADR-0015 `ModelClient(backend=...)` seam returning a scripted recommendation that echoes the summary's
`genetic-trait-classes`; the `aplus-research` variant dispatch is the T4 STUB (`dispatcher=None` dry-run, 0 outbound
call); the run is deterministic + CI-runnable with no network, no key. The operator-present LIVE run (real
`aplus-research` variant lookups + real spend + real time, end-to-end through dispatch → de-associated query → gated
library cache → local match → DNA-aware plan, the OS-egress-guard LIVE form of the de-association + raw-genotype-to-planner
probes) is OQ-1, the operator-gated checkpoint AFTER this build, NOT a CI gate.

The TWO load-bearing test properties: **(a)** the headline E2E goes RED if it produces the no-DNA state (the plan
signal carries no genetic trait / the token is hardcoded / a no-match fabricates a trait) instead of a USABLE
current-science trait — a tautological "a plan was produced" assertion is forbidden; it asserts the plan signal's
recommendation TRACES to the FIXTURE finding's trait class (a DIFFERENT fixture genotype → a DIFFERENT trait class in
the plan signal — A≠B), with a failing-capable negative control proving it distinguishes a DNA-derived signal from the
no-DNA state; **(b)** it is mock/fixture-testable (no live API, no key, no live `aplus-research`, 0 spend). The headline
is proven through BOTH the explicit-fixture-root call (`summarize(store_read, genetics_library_root=<fixture>)`) AND the
PRODUCTION no-arg call path (`summarize(store_read)` with the deriver's module-level default root monkeypatched to the
fixture library — **FIX-1 / CQ-1**), so the capability is proven on the frozen production signature the live callers
use, not only on the explicit-fixture injection. The TDD Steps follow RED/GREEN/REFACTOR/REGRESSION, GREEN here meaning
"the binding test passes against the already-built mechanism" — this task wires NO new production code; if the E2E goes
RED for a real mechanism gap, that routes back to the owning Wave-1/2 task (T1 the genetics gate / T2 the matcher / T3
the router deriver / T4 the query stub), not a fix authored here.

T5's eight enumerated ACs are the non-tautological headline trait-in-plan land (AC-1), the failing-capable negative
control (AC-2), the crown-jewel egress [de-association + library-association] probe (AC-3), the
raw-genotype-never-reaches-the-no-train-planner probe (AC-4), the EXTEND-NOT-REBUILD numstat over the frozen
engine+store (AC-5), the ingestion-gated + honest-no-match probe (AC-6), the mock-tested 0-live-spend proof (AC-7), and
the pytest-passes close (AC-8). The build plan's Wave-3 → Done boundary ADDS the **FIX-1 / CQ-1 PRODUCTION NO-ARG E2E**
criterion (the headline driven through the frozen `summarize(store_read)` signature, with a matching-page-removed
negative control distinguishing "wired to the real default, no match" from "feature disabled") — carried here as a named
fold-in beyond the 8 enumerated spec ACs (see the Report spec-note). T5 depends on T1 (the ingestion gate it
re-asserts), T3 (the wired `summarize` genetic-trait token it drives through the author seam), and T4 (the de-associated
query stub its egress probe inspects); it depends on T2 transitively (T3's deriver + T4's stub both import T2's
`scripts.genetics` modules). T5 shares no file with any other task (it is the single Wave-3 task; the file it creates is
its own).

**The five ADR-0032 falsification probes, each FAILING-CAPABLE (RED on the broken behavior; QA-F3 per-probe annotation):**
**(1) crown-jewel egress** [de-association + library-association] — AC-3; REDs if the `build_variant_query` output for
the fixture variant carries an operator-identity token OR a raw-genotype (rsID+allele) token OR is not allele-agnostic
(`assert_query_de_associated` would NOT raise on it / the built query leaks), OR if the fixture `vault/library/genetics/`
page scan via `pii_scan.scan_text` returns ≥1 operator token. **(2) raw-genotype-never-reaches-the-no-train-planner** —
AC-4; REDs if a seeded raw genotype (`item="MTNR1B rs10830963"`, `value="(C;G)"`) appears in ANY `dispatch` payload
VALUE (`rs\d+` or `\([ACGTDI]+;[ACGTDI]+\)`) — i.e. the deriver leaked the raw genotype into the de-id summary instead
of the coarse trait class. **(3) EXTEND-NOT-REBUILD** — AC-5; REDs if `git diff --numstat <fork-point>` over the 9
frozen engine files + the `scripts/store/*` glob emits ANY row (a frozen engine/store file was edited — a rebuild, not
the additive `router.py` change). **(4) ingestion-gated** — AC-6; REDs if an ungated genetics fixture page (missing
provenance / `gene`-`rsid` / `## Genotype Findings`) is NOT blocked by `wiki-ingest-lint.sh` (exit 0 where exit 1 is
required — a genetics waiver). **(5) honest-no-match** — AC-6; REDs if a curated variant with no library page produces a
FABRICATED trait token (appears in the match / the summary token) instead of being reported in
`unmatched_planning_variants`, OR if a seeded APOE/excluded genotype IS matched or queried.
