# Recipe: The `/chat` Egress Seam — One Turn In / One Turn Out, Fail-Closed, Per-Turn Extraction

This task produces CODE: the POST `/chat` route on `scripts/serve/server.py` (the route table →
{GET `/`, POST `/upload`, POST `/chat`}; the `_LOOPBACK = "127.0.0.1"` bind literal byte-unchanged,
[server.py:29,222](../../scripts/serve/server.py#L29) [VERIFIED]) and the per-turn dispatch in
`scripts/serve/chat.py` (`plan_next_turn` → `client.converse` → `extract_facts` → `persist_capture`
→ the per-turn receipt). It is the wave's LEAF — it wires the strategy (`ADR-0015-T2`), the client
(`ADR-0015-T1`), and the extractor (`ADR-0017-T1`) into the per-turn dispatch over the UNCHANGED
loopback server. It makes the system's FIRST authorized outbound model call — but the ONE outbound
call is the model call through `scripts/model/client.py` on the no-train lane, carrying the live
conversation (raw) + the de-identified context and NOTHING else (the crown-jewel single-egress-class
boundary, NFR-1; ADR-0016 Falsification: any raw egress other than the live conversation =
release-blocking). The extractor runs per turn (CONCERN-2: per-turn extraction, the transcript
residency is one turn). A failed/timed-out/rate-limited/empty model call returns a degraded turn
(no fabricated reply, no fabricated fact, no store write) and never kills the request thread. Built +
tested against a MOCK client (a scripted fake `converse`, no live API). The TDD Steps follow the
standard RED/GREEN/REFACTOR/REGRESSION cycle.

## Interface Contracts

This task PUBLISHES the `/chat` egress seam + the per-turn dispatch, consumed by `ADR-0017-T2`'s end-to-end conversation, so the contract is load-bearing.

- **Route:** POST `/chat` on `IntakeRequestHandler` in `scripts/serve/server.py` — **NAMED CONTRACT:** a sibling route on the SAME loopback `ThreadingHTTPServer(("127.0.0.1", port), ...)`; the route table is {GET `/`, POST `/upload`, POST `/chat`}. **Invariants (load-bearing):** (a) the `_LOOPBACK` bind literal is byte-unchanged — no new bind (AC-1, ADR-0013 Negative-1); (b) the ONE outbound call is the model call via `scripts/model/client.py` on the no-train lane, carrying the live conversation (raw) + the de-identified context and nothing else — 0 store content / 0 other operator's transcript (AC-3, NFR-1, the crown-jewel single-egress-class boundary); (c) a failed model call returns a degraded turn (no fabricated reply/fact, no store write) and never kills the thread (AC-5, AC-6, NFR-2). **Dependent:** `ADR-0017-T2`'s end-to-end conversation drives `/chat` turns; `ADR-0018-T1`'s activated form links to the `/chat` panel.
- **Dispatch:** the per-turn dispatch in `scripts/serve/chat.py` — `plan_next_turn` → `client.converse` → `extract_facts` → `persist_capture(..., identity_config=...)` → the per-turn receipt. **Invariant (load-bearing, CONCERN-2):** the extractor runs EACH turn (the transcript residency is one turn; the next-turn gap-set is computed against what LANDED, not the model's claim). The `/chat` capture call threads `identity_config` (the `/chat` half of `ADR-0017-T1`'s H-2 dual-call-site wiring). **Change control:** no second outbound call and no artifact-serving route may be added without re-opening ADR-0016 against the single-egress-class boundary.
