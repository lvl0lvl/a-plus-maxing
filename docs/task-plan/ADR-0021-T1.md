## Interface Contracts

This task creates the following interface consumed by ADR-0025-T1 (the maintained-HTML output, which runs the deterministic name-fill as the FINAL pass over the produced HTML — runtime-stage-order step 6, format-then-fill):
- Function: `reinsert_out(html, target_path)` — takes the produced HTML string and the render target path; RETURNS A STRING (the artifact content) with the real operator name re-inserted when `target_path` is confirmable-gitignored, else the initials-only `html` unchanged (fail-closed). It does NOT write — the CALLER (ADR-0025-T1) owns the write to the SAME path it `git check-ignore`-confirmed. `target_path` is the gate input (the confirm), not a write target.
- Behavioral contract: deterministic, model-free (no model on the OUT path); re-inserts ONLY when `git check-ignore <target_path>` confirms gitignored; writes NOTHING (no artifact, no persisted store — the caller writes); the name-fill is idempotent over already-name-bearing HTML (a later render must not clobber a re-inserted name — ADR-0025-T1 crit 6 rests on this).
- TOCTOU note (defense-in-depth, not authority): the in-process `git check-ignore` confirm is best-effort (the confirm and the caller's subsequent write are non-atomic). The fail-closed AUTHORITY that no name-bearing tracked file commits is the commit/push PII hooks (T0-SCANSCOPE coverage), not this confirm.
- Dependent task: ADR-0025-T1 (per the spec dependency map: ADR-0021-T1 → ADR-0025-T1).
- Dependent tasks MUST NOT change this interface without Architect review.
