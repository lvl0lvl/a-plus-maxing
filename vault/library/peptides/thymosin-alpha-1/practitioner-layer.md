# Thymosin Alpha-1 — Prescribing-Practice Layer

`practitioner_protocol` cites may support dose/route/cycle conventions ONLY — never efficacy, AE rates,
or mechanism (those require Tier 1/2).

## Approved / authoritative dosing (regulatory — the reference for any off-label use)
- **Chronic hepatitis B (approved): 1.6 mg SC twice weekly** (≈3–4 days apart), 6–12 months; **40 µg/kg** if <40 kg `[regulatory: Zadaxin PI]`.
- **Severe sepsis (ETASS regimen): 1.6 mg SC twice daily ×5 days, then once daily ×2 days** (7-day course) `[rct: PMID 23327199]`.
- **Administration:** SC only (NOT IV); reconstitute lyophilized powder with 1.0 mL Sterile Water → 1.6 mg/mL; use immediately; store 2–8 °C `[regulatory]`.

## Doctor-handout note
Low-risk and WADA-legal, but unproven for general recovery and not FDA-approved. A doctor-handout candidate for
immune restoration **only if a specific clinical indication arises** — discussed at the July-2026 visit, under MD supervision.
