# Hexarelin — Phase 2.5 Rubric + Section Plan (deep mode, efficient calibration)

## Mode
deep mode (25+ sources, ~10k words) under the **efficient calibration**: judge bar **92**;
genuine-defects-only; ONE remediation round per real defect.

## THE DEFINING FACTS (integrity axes)
1. **Hexarelin is a GHRP — a ghrelin-receptor (GHSR-1a) agonist** (synthetic hexapeptide
   His-D-2-Me-Trp-Ala-Trp-D-Phe-Lys-NH2), the SAME receptor class as GHRP-6 / GHRP-2 /
   ipamorelin. It is **NOT a GHRH analogue** (do not confuse with sermorelin/CJC-1295/
   tesamorelin, which act on the GHRH receptor). It also binds **CD36** (scavenger receptor) —
   the basis for GH-independent cardiac research.
2. **Tachyphylaxis / desensitization is the defining limitation:** sustained dosing
   down-regulates the GH response (GHSR desensitization). Acute GH release ≠ durable effect —
   do NOT let acute-PD GH spikes read as sustained body-comp/anti-aging efficacy.
3. **Less SELECTIVE than ipamorelin:** hexarelin meaningfully raises cortisol / prolactin / ACTH
   (unlike ipamorelin's clean selectivity) — state this honestly.
4. **No approval, no Phase 3 efficacy** for body-comp/anti-aging; human data is acute-PD +
   small short studies (GHD children, elderly) + cardiac/CD36 work. Italian originator lineage
   (University of Turin — Ghigo/Arvat/Broglio; developer Mediolanum/Deghenghi).

## Section plan (6 lean sections)
- **A — Identity, structure, mechanism.** Hexapeptide structure; GHSR-1a (ghrelin-receptor)
  agonism + CD36 binding; contrast GHRH analogues + the GHRP family; potency; PK (short t½).
- **B — Human GH pharmacology + the tachyphylaxis limitation.** Acute GH release magnitude
  (Ghigo/Arvat human PD); the desensitization/down-regulation with chronic dosing (the
  defining limitation); cortisol/prolactin/ACTH co-elevation (non-selectivity).
- **C — Clinical evidence + concentration audit (demarcate honestly).** GHD children, elderly,
  any body-comp; the cardiac/CD36 cardioprotection research (Broglio/Bisi). Label
  evidenced vs INVESTIGATIONAL vs ABSENT (anti-aging/athletic = no robust data). Concentration
  audit — Turin/Ghigo + Mediolanum lineage share; flag ≥70%.
- **D — Safety / adverse effects.** Cortisol/prolactin/ACTH elevation; cardiac effects
  (double-edged — cardioprotection signal vs hemodynamic effects); desensitization; glucose/
  insulin; contraindications; monitoring (IGF-1 + glucose + prolactin/cortisol if chronic).
- **E — Regulatory & sport.** Never approved (no FDA/EMA); §503A status — hexarelin is NOT in
  the canonical Apr-2026 removed-12 (BPC-157, TB-500, KPV, MOTS-c, DSIP/Emideltide, Semax,
  Epitalon, GHK-Cu, Melanotan-II, Dihexa, PEG-MGF, LL-37) — verify its actual standing (likely
  unlisted/Cat-2; don't guess); FR Doc 2026-07361 = July-2026 PCAC notice (not "the removal").
  WADA S2.2 prohibited (GH secretagogue). Gray-market reality.
- **F — Practitioner-practice + non-English.** Convention ~100 mcg SC 1-3×/day with cycling
  driven by desensitization (e.g. short courses); compounding availability; Italian (originator,
  likely English-published) + Russian + Chinese literature survey.
