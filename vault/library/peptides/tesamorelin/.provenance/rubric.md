## Mode
deep mode (25+ sources, ~10k words) under the **efficient calibration**: judge bar **92**

## THE DEFINING FACT (must be right everywhere — the integrity axis for this compound)
Tesamorelin (TH9507; brand **Egrifta / Egrifta SV / Egrifta WR**; Theratechnologies) is the
**ONLY FDA-APPROVED GHRH analogue** in this peptide cluster — approved (2010) for **reduction
of excess visceral abdominal fat in HIV-associated lipodystrophy**. So unlike CJC-1295 /
ipamorelin / sermorelin, it HAS real Phase 3 RCT efficacy. BUT that efficacy is for a NARROW
approved population/endpoint (HIV-lipodystrophy VAT). **The integrity risk is letting the
approved-indication efficacy masquerade as proven general anti-aging / bodybuilding /
fat-loss / muscle efficacy — which is OFF-LABEL EXTRAPOLATION, not approved/proven.** Demarcate
sharply: APPROVED (HIV-lipodystrophy VAT) vs INVESTIGATIONAL (NAFLD/NASH, cognition) vs
ABSENT (general anti-aging / athletic).

Structure: a stabilized synthetic **GHRH(1-44)NH2** analogue (trans-3-hexenoyl group on the
N-terminus for protease stability) — NOT the GRF(1-29) core that CJC-1295/sermorelin use.
GHRH-receptor agonist → pulsatile GH → hepatic IGF-1. Effects REVERSE on discontinuation.

## Section plan (6 lean sections)
- **A — Identity, structure, mechanism.** GHRH(1-44) analogue; the trans-3-hexenoic-acid
  N-terminal modification; GHRH-R → cAMP/PKA → pulsatile GH → IGF-1; contrast GRF(1-29)
  analogues; reversibility.
- **B — Approved-indication human efficacy (the STRONG section).** Falutz 2007 (NEJM) +
  Falutz 2010 Phase 3 RCTs in HIV-lipodystrophy: design, n, VAT reduction (~15-18%), IGF-1,
  triglycerides, the 26→52-week maintenance/withdrawal data (effect reverses off-drug).
  Verify the pivotal PMIDs/NCTs exactly.
- **C — Beyond-label human evidence (demarcate honestly).** NAFLD/liver fat in HIV
  (Stanley 2014 Lancet HIV; Fourman/Stanley follow-ups), cognition in older non-HIV adults
  (Baker 2012 Arch Neurol), any other population. Label each APPROVED / INVESTIGATIONAL /
  no-human-data. NO general anti-aging or athletic efficacy exists — state plainly.
- **D — Safety / adverse effects (well-characterized — it's approved).** From the RCTs +
  the FDA label: glucose/insulin effects + IGF-1 elevation, arthralgia, myalgia, peripheral
  edema, injection-site reactions, hypersensitivity (incl. mannitol/excipient). Contra-
  indications (label): pregnancy, active malignancy, disrupted hypothalamic-pituitary axis
  (hypophysectomy/hypopit/head irradiation/trauma), hypersensitivity. Monitoring: IGF-1,
  fasting glucose/HbA1c. Discontinuation reverses effect.
- **E — Regulatory & sport status.** FDA-APPROVED (Egrifta 2010; Egrifta SV reformulation;
  Egrifta WR newer) — Theratechnologies; the EXACT approved-indication wording. EU/EMA:
  verify (not approved / withdrawn?). 503A/compounding status. WADA: prohibited at all times,
  **S2.2 (GHRH/GH-releasing factors) — tesamorelin named.** Off-label/gray-market reality.
- **F — Practitioner-practice + non-English.** Label dose (Egrifta 2 mg SC daily; Egrifta SV /
  WR ~1.4 mg SC daily — verify); off-label anti-aging dosing conventions (practitioner_protocol);
  reconstitution; cost (it is expensive brand Rx); Russian/Chinese literature survey.

## RECURRING-ERROR SELF-CHECKS — every retrieval agent runs these before returning

   not cite an identifier you didn't open. (wrong-PMID class — bit every prior entry.)
2. **FDA status:** state the EXACT approved indication + approval year + brand(s); approval ≠
   license for off-label uses. Verify against fda.gov/dailymed/accessdata.
3. **NO Wikipedia citations** (mechanical HALT). No vendor/anecdote grounding a numerical claim.
4. **Tally-vs-enumeration:** any "N trials show X" backed by an enumerated list of exactly N.
5. **Approved-vs-extrapolated discipline:** never let HIV-lipodystrophy-VAT efficacy read as
   general anti-aging/bodybuilding/fat-loss/muscle efficacy. Annotate the trial population.
6. **Type-tag every claim**; vendor/anecdote never ground numbers.
7. **Population annotation** on the human pivotal trials (HIV-lipodystrophy) is mandatory.
