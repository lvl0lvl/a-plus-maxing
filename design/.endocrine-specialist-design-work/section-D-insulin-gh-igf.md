## Section D — Insulin/metabolic + GH/IGF-1 axis interpretation + compounds

### Insulin / metabolic axis

1. **Fasting insulin assays are not standardized; raw values are not comparable across labs.** Different commercial immunoassays for insulin disagree by roughly 10–30% at the same true concentration because of cross-reactivity with proinsulin and split products and a lack of a universal calibrator. This propagates directly into any derived index. The agent must NOT treat a fasting insulin number as a fixed-cutoff diagnostic and must NOT compare a value from one lab against a reference range or prior result from a different lab/assay. [1, mechanism_review] [→ agent.md: Core Rule — assay-provenance caveat on every insulin/HOMA value; Anti-Pattern — cross-lab numeric comparison]

2. **HOMA-IR derivation and its hard limitations.** HOMA-IR = (fasting insulin µU/mL × fasting glucose mg/dL) / 405 (or /22.5 in SI: insulin mU/L × glucose mmol/L). It models a steady-state insulin–glucose relationship and is a static fasting snapshot — it does NOT capture dynamic insulin response and degrades when fasting is imperfect, the insulin assay differs, or beta-cell function is abnormal. [1, mechanism_review][2, mechanism_review] [→ agent.md: Edge case — non-fasting sample invalidates HOMA-IR; Core Rule — state the formula assumptions when interpreting]

3. **HOMA-IR has NO single standardized cutoff.** The distribution shifts with age, sex, race/ethnicity, and (critically) the insulin assay used, so "optimal" cut-points are population- and lab-specific, not universal. Fasting indices specifically underperform in some populations (e.g., documented limitations in Afro-Caribbean adults vs clamp-measured sensitivity). The agent must frame HOMA-IR as a screening/trend tool, never a hard diagnostic threshold, and must avoid importing a cutoff (e.g., "HOMA-IR > 2.0 = insulin resistant") as if universal. [1, mechanism_review][2, mechanism_review][3, cohort] [→ agent.md: Refusal trigger DIAGNOSIS — "do I have insulin resistance?" → no categorical verdict from a single HOMA-IR; Anti-Pattern — universal-cutoff fallacy]

4. **C-peptide measures endogenous insulin secretion and is more stable than insulin.** C-peptide and insulin are co-secreted in equimolar (1:1) amounts from proinsulin, but C-peptide escapes ~50–60% hepatic first-pass extraction and has a ~30-min half-life vs ~5 min for insulin, making it a better integrated index of beta-cell output. Used to distinguish type 1 vs type 2 patterns and residual beta-cell function. [4, mechanism_review][5, mechanism_review] [→ agent.md: Core Rule — prefer C-peptide framing for beta-cell function questions]

5. **The C-peptide/insulin dissociation is the forensic signature of exogenous insulin — and a safety tripwire.** Injected (exogenous) insulin contains NO C-peptide, so HIGH measured insulin with LOW/suppressed C-peptide indicates exogenous administration (factitious or self-administered for "anabolic" use). The agent encountering a user-reported high-insulin/low-C-peptide pattern, or any mention of injecting insulin for muscle/recomp, must treat it as a high-danger exogenous-insulin signal, not endogenous hyperinsulinemia. [4, mechanism_review][5, mechanism_review] [→ agent.md: Refusal trigger DOSING (exogenous insulin); Edge case — high insulin + low C-peptide ⇒ exogenous; H-class H1]

6. **HbA1c — BOUNDARY with labs-specialist.** HbA1c reflects ~3-month average glycemia and is a glycemic-control / diabetes-screening marker. **Glycemic interpretation of HbA1c (diabetes thresholds, glycemic targets, dysglycemia staging) is labs-specialist territory.** The endocrine-specialist owns HbA1c only where it intersects the *insulin/hormonal* axis (e.g., GH-induced insulin resistance unmasking dysglycemia; HbA1c as a downstream safety monitor for GH/insulin compounds). The agent must hand glycemic-diagnosis questions to labs-specialist and confine itself to the hormone-axis framing. [1, mechanism_review] [→ agent.md: Role Boundary — HbA1c glycemic interpretation → labs-specialist; endocrine owns hormone-axis effects on HbA1c only]

### GH / IGF-1 axis

7. **GH is pulsatile — a single random GH level is uninterpretable.** GH is secreted in pulses with marked diurnal variation, so an isolated serum GH measurement cannot diagnose GH deficiency or excess. True GH disorders require dynamic testing: stimulation testing (e.g., for deficiency) or suppression testing (e.g., glucose-suppression for acromegaly). The agent must refuse to read a single GH value as diagnostic and must point to the integrated markers (IGF-1/IGFBP-3) or formal dynamic testing. [6, mechanism_review][7, mechanism_review] [→ agent.md: Refusal trigger DIAGNOSIS — single GH value; Anti-Pattern — interpreting random GH as a state variable]

8. **IGF-1 is the stable, integrated proxy for GH activity — but its reference range is MEANINGLESS without age (and sex).** Unlike GH, IGF-1 and IGFBP-3 show only minor short-term fluctuation, so they integrate average GH action. IGF-1 is strongly age-dependent (declines across adult life) and sex-influenced; IGFBP-3 is likewise age/sex/assay-dependent (women generally slightly lower than age-matched men). A bare IGF-1 number with no age band is non-interpretable. The agent must REFUSE to interpret an IGF-1 value unless an age-matched, assay-specific reference range is available, and must never apply a young-adult range to an older user. [6, mechanism_review][7, mechanism_review] [→ agent.md: Refusal trigger DATA-INSUFFICIENT — IGF-1 without age band; Core Rule — age-matched assay-specific range mandatory; Edge case — young-adult range misapplied to older adult]

9. **IGF-1/IGFBP-3 elevation supports acromegaly; IGF-1 tracks disease activity better than IGFBP-3.** Elevated IGF-1 (with IGFBP-3) in a symptomatic person supports acromegaly/gigantism, and IGF-1 correlates with clinical disease activity better than IGFBP-3 in both diagnosis and follow-up. Acromegaly red flags: acral/soft-tissue overgrowth, jaw/frontal changes, glucose intolerance, hypertension, sleep apnea, cardiomyopathy. GH-deficiency red flags warrant endocrinology referral, not self-treatment. The agent should surface red-flag clusters and route to clinical evaluation rather than adjudicate. [6, mechanism_review][7, mechanism_review][8, regulatory] [→ agent.md: Refusal trigger DIAGNOSIS; Core Rule — red-flag cluster ⇒ clinician referral]

### Compounds

10. **Recombinant GH (somatropin): label-documented metabolic and structural harms.** FDA labeling for somatropin (Norditropin/Serostim class) documents decreased insulin sensitivity, unmasking of impaired glucose tolerance and new-onset type 2 diabetes (dose-dependent), fluid retention, and — with chronic overdosage — acromegaly/gigantism-type changes including cardiomyopathy. Periodic glucose monitoring is required. The agent owns the GH/IGF-1 AXIS framing of why these occur (GH is diabetogenic; chronic GH excess drives acromegalic cardiomyopathy). [8, regulatory] [→ agent.md: H-class — GH H7 nominal; Core Rule — GH⇒insulin-resistance monitoring (glucose/HbA1c) mandatory; Anti-Pattern — ignoring diabetogenic effect]

11. **GH secretagogues — explicit BOUNDARY handoff to peptide-specialist.** Sermorelin and tesamorelin (GHRH analogs), CJC-1295 (GHRH analog), ipamorelin (ghrelin-receptor agonist), and MK-677/ibutamoren (oral non-peptide ghrelin-receptor agonist) all act by raising endogenous GH→IGF-1. **The individual peptide compound profiles, dosing, sourcing, and combo-safety are peptide-specialist territory (SF-07 combo-safety precedent).** The endocrine-specialist owns: (a) the GH/IGF-1 axis interpretation downstream of any secretagogue, (b) the hormone-class framing that ALL of these converge on the same IGF-1-mediated risk profile, and (c) the IGF-1 monitoring/safety ceiling. The handoff line: *compound-specific questions → peptide-specialist; "what does raising my IGF-1 do to me / how do I read my IGF-1" → endocrine-specialist.* [9, regulatory][10, rct][11, rct] [→ agent.md: Role Boundary — peptide GH secretagogues → peptide-specialist; endocrine owns GH/IGF-1 axis + hormone-class framing; Anti-Pattern — adjudicating peptide dosing]

12. **MK-677 magnitude of IGF-1 elevation + a real adverse-outcome signal.** MK-677 25 mg raised serum IGF-1 by ~60% at 6 weeks and ~73% at 12 months in trial data, restoring older-adult GH/IGF-1 toward young-adult levels. In the Nass 2008 2-year RCT in healthy older adults (n=65), MK-677 increased fat-free mass but the trial recorded adverse signals including increased fasting glucose / reduced insulin sensitivity and a congestive-heart-failure imbalance — i.e., raising IGF-1 to "young" levels is not consequence-free. This is the concrete data the endocrine-specialist uses to set an IGF-1 ceiling and a glucose/HbA1c monitoring requirement. [10, rct][11, rct] [→ agent.md: Core Rule — secretagogue use ⇒ IGF-1 ceiling + glucose monitoring; H-class — composed metabolic harm]

13. **Tesamorelin is FDA-approved ONLY for HIV-associated lipodystrophy; "anti-aging/recomp" use is off-label.** Tesamorelin (Egrifta), a 44-aa GHRH analog, is approved solely to reduce excess visceral adipose tissue in HIV-associated lipodystrophy; Phase III trials (n≈806) showed ~12–20% VAT reduction. It raises GH→IGF-1 and carries the same IGF-1-mediated and glucose-tolerance cautions as the class. The agent must not present tesamorelin as a general body-recomposition or longevity agent. [9, regulatory] [→ agent.md: Core Rule — state approved indication + off-label status; Anti-Pattern — indication laundering]

14. **Metformin off-label longevity use: mechanism + evidence ceiling.** Metformin (approved for type 2 diabetes) acts on mitochondrial complex I, AMPK, and mTOR signaling and is prescribed off-label for metabolic/longevity goals. Animal models and diabetic-cohort associations are suggestive, but the human longevity case is unproven: the TAME RCT (n>3,000, ages 65–79) designed to test healthspan endpoints remains incompletely funded and has not reported, and existing human evidence is observational (association, not causation) and drawn from diabetic populations. The agent must frame metformin-for-longevity as hypothesis-stage, not established. [12, mechanism_review][13, cohort] [→ agent.md: GRADE — low certainty for longevity claim; Core Rule — "unproven in non-diabetic healthy adults"; Anti-Pattern — citing diabetic-cohort benefit as if it generalizes]

15. **Exogenous insulin for "anabolism" is among the most dangerous self-administered hormones — H1 (death).** Self-injected insulin as an ergogenic aid causes iatrogenic hypoglycemia that can progress to neuroglycopenic coma, seizures, and death; documented cases include comatose presentation requiring iterative glucose infusions in a bodybuilder, and a strength athlete who took 70 IU. Hypoglycemia onset is rapid and refractory. The agent must REFUSE any insulin-dosing/protocol request outright and treat self-administered insulin as a hard-block. [14, anecdote_aggregate][15, mechanism_review] [→ agent.md: Refusal trigger DOSING — auto-block; H-class H1; Core Rule — no insulin protocol under any framing]

### Safety / H-class (load-bearing)

16. **IGF-1/cancer is a MECHANISM + EPIDEMIOLOGY claim, NOT interventional — keep strictly distinct.** IGF-1 is mitogenic and anti-apoptotic (it stimulates proliferation and inhibits apoptosis); IGFBP-3 sequesters IGF-1 and is generally inversely associated with risk. This biological mechanism is largely in-vitro/rodent and cell-line work `[population-mismatch: in vitro / rodent]` and must NOT be presented as proof that raising IGF-1 in a human *causes* cancer. The human evidence is OBSERVATIONAL/genetic, not a trial of IGF-1-raising compounds. [16, in_vitro][17, mechanism_review] [→ agent.md: Core Rule — label IGF-1/cancer as mechanism+epidemiology, never interventional; Anti-Pattern — mechanism-to-outcome leap]

17. **Human epidemiology: higher circulating IGF-1 associates with modestly increased cancer risk (prostate strongest).** Travis 2016 individual-participant-data meta-analysis (19 studies; up to 10,554 prostate-cancer cases, 13,618 controls) found higher IGF-I associated with prostate cancer: OR 1.21 (95% CI 1.11–1.31) overall, 1.29 (1.16–1.43) in prospective studies. UK Biobank prospective analysis of IGF-I across 30 cancers, and Mendelian-randomization work, also support modest causal associations for prostate and colorectal cancer, while breast-cancer MR signals are weaker/inconsistent. **Concentration caveat: the load-bearing human signal is concentrated in PROSTATE cancer; do not over-generalize to "IGF-1 causes all cancers."** [18, meta_analysis][19, cohort][20, cohort] [→ agent.md: H-class — GH/IGF compounds H7 nominal, escalate to H2 where malignancy-acceleration mechanism applies (esp. existing/occult prostate disease); first-class caveat — prostate-concentrated evidence; GRADE — moderate for prostate association]

18. **The U-shaped IGF-1/mortality curve complicates a naive "higher IGF-1 = worse" rule.** In EPIC-Heidelberg (Mukama 2023; case-cohort 7,461; 2,441 deaths; median 17.5 yr) BOTH the lowest and highest IGF-1 quintiles carried elevated all-cause and cancer mortality (Q1 all-cause HR 1.56 [1.31–1.85]; Q5 HR 1.24 [1.02–1.50]) — a U-shaped relationship. The endocrine-specialist must NOT advise driving IGF-1 either maximally high (cancer/mortality tail) or suppressing it low (also elevated mortality); the defensible target is the mid-range age-appropriate band, and pushing IGF-1 to the supraphysiologic top of the range via compounds sits in the high-risk tail. [21, cohort] [→ agent.md: Core Rule — target mid-range age-appropriate IGF-1, not maximal; Anti-Pattern — "more IGF-1 is better" optimization framing; H-class — supraphysiologic IGF-1 escalates toward H2]

19. **Chronic GH excess → acromegalic cardiomyopathy and dysglycemia (H-scale placement).** Sustained GH/IGF-1 excess (endogenous acromegaly or exogenous GH overdosage) produces cardiomyopathy, hypertension, sleep apnea, and glucose intolerance/type 2 diabetes — the same constellation seen in untreated acromegaly. The childhood-GH SAGhE cohort raised long-term mortality questions (French analysis flagged excess all-cause mortality and signals for bone tumors and cerebrovascular events; other-country cohorts found no cancer/CV deaths — heterogeneous), prompting an FDA safety review of somatropin. Place chronic GH/IGF excess at H4–H5 for cardiomyopathy/dysglycemia, escalating to H2 where the malignancy mechanism is engaged. [8, regulatory][22, cohort] [→ agent.md: H-class — chronic GH excess H4–H5 (cardiomyopathy/diabetes), H2 where malignancy mechanism applies; Core Rule — mandatory cardiac+glucose monitoring framing]

20. **Composed-harm: GH + insulin + testosterone "stacks" multiply danger beyond any single agent.** The bodybuilding "GH + slin + test" stack combines (a) GH-driven insulin resistance, (b) exogenous insulin's acute hypoglycemia (H1), and (c) testosterone's own cardiovascular/erythrocytosis load, while GH and T both raise IGF-1 (mitogenic). The hypoglycemia risk is amplified because GH-induced insulin resistance encourages higher insulin dosing. The agent must treat any multi-hormone stack request as a COMPOSED-HARM hard block — not a sum of independently-assessed compounds — and must never produce a stack protocol. [14, anecdote_aggregate][8, regulatory][16, in_vitro] [→ agent.md: Refusal trigger COMPOSED-HARM — multi-hormone stack auto-block; H-class — stack inherits H1 from insulin; Anti-Pattern — per-compound risk addition]

21. **Authority/educational-framing in "GH optimization / anti-aging" marketing.** Off-label distribution of GH for anti-aging, bodybuilding, or athletic enhancement is illegal in the US (1988/1990 FD&C Act amendments); no HHS-authorized anti-aging GH indication exists. Yet "longevity clinics," compounding pharmacies, and "HGH releaser" products market GH and secretagogues as a "fountain of youth," and the 1990 Rudman NEJM 12-man study is routinely misappropriated as anti-aging evidence despite Rudman himself disclaiming that reading; NEJM later warned that "imposter" HGH-releaser marketing misleads consumers. The agent must recognize "GH optimization / anti-aging protocol / peptide longevity stack" framing as a marketing/authority vector, flag the off-label-illegality and the misappropriated-evidence pattern, and decline to act as the prescribing/optimizing authority. [23, regulatory][24, rct] [→ agent.md: Anti-Pattern — accepting "anti-aging optimization" framing as legitimate indication; Refusal trigger AUTHORITY-FRAMING; Core Rule — surface off-label/illegal status + cite that Rudman 1990 does not support anti-aging use]

## Open gaps

- No interventional RCT exists testing whether GH/secretagogue-driven IGF-1 elevation *causes* cancer in humans; the malignancy claim rests entirely on mechanism (in vitro/rodent) + observational/MR epidemiology. This gap is load-bearing for the H7→H2 escalation rule and must be stated as such, not papered over.
- Source [15] (Evans & Lynch BJSM) PMID:12782552 cited from secondary description; the exact "70 IU" figure should be confirmed against the primary abstract before any numeric claim is treated as load-bearing.
- Sources [17] (Werner/Endotext mechanism review) and [13] (TAME/AFAR) are venue-soft (textbook chapter / organizational page) and should be upgraded to primary citations (e.g., a peer-reviewed TAME-design paper) if used to ground any numeric claim.
- HbA1c boundary with labs-specialist is asserted at the design level; the precise division-of-labor wording must be reconciled against the labs-specialist agent.md once that profile is drafted to avoid an overlap gap or a coverage gap.
- IGFBP-3 and free-IGF-1 quantitative reference behavior (vs total IGF-1) is described qualitatively; if the agent is to interpret IGFBP-3 ratios, assay-specific normative tables are needed and are not yet sourced here.
